<DESCRIPTION>
This edit refines the scheduling heuristic with several improvements:

1.  **Priority-based Procrastination Penalty**: Introduces `PROCR_PENALTY_FACTORS` constants to apply a dynamic penalty for delaying an operation's start time, scaled by the job's priority. Emergency jobs incur a higher penalty for waiting, encouraging prompt scheduling, while lower priority jobs have more flexibility. This penalizes the 'wait_time' (actual start minus earliest possible start) making the scheduler less prone to "procrastinate" on high-priority tasks.
2.  **Dynamic Slack-Based Search Horizon**: The search window for local machines is no longer a fixed `2 * inst.time_horizon`. Instead, it is dynamically determined by the job's remaining "slack" (`job.deadline - current_projected_completion`). Jobs with tight deadlines or negative slack get a shorter search horizon to prioritize immediate placement, while jobs with ample slack can explore a wider range of future slots for cost optimization (e.g., finding off-peak hours). A `MAX_ABSOLUTE_SEARCH_WINDOW` is also introduced to prevent excessively long searches for very flexible jobs.
3.  **Best-Fit Local Machine Search**: The local machine search logic is changed from a "first-fit" (using `break` after finding the first available slot) to a "best-fit" within the dynamic search horizon. This ensures the algorithm evaluates all feasible slots on all compatible local machines within the determined window and picks the absolute best one, leading to more optimal resource utilization and cost reduction.
4.  **Consolidated Scoring Function**: The `operation_objective_improved` function is updated to include the procrastination penalty, ensuring all cost components are calculated uniformly.
5.  **Refined Cloud Fallback**: The logic for cloud placement is slightly adjusted to consider the overall `best_placement` more carefully, ensuring that if local machines can't beat the cloud within the dynamic horizon, the cloud is chosen, or an exhaustive local search is performed as a last resort.
</DESCRIPTION>

PRIORITY_FACTORS = {
    "Emergency": 3.0,  # Higher penalty for emergency jobs
    "High": 2.0,       # High penalty for high priority
    "Medium": 1.0,     # Default penalty
    "Low": 0.5         # Lower penalty for low priority
}
CLOUD_COST_MULTIPLIER = 1.5 # Make cloud machines more expensive to encourage local usage

def operation_objective_improved(inst, server_id, start, op, job, remaining_duration, is_cloud):
    """
    Calculates the objective cost for a given operation, incorporating priority-based
    delay penalties and cloud cost multiplier.
    """
    compute = sum(inst.server_cost[server_id][t % inst.time_horizon]
                  for t in range(start, start + op.duration))

    if is_cloud:
        compute *= CLOUD_COST_MULTIPLIER

    projected_completion = start + op.duration + remaining_duration
    delay = max(0, projected_completion - job.deadline)

    # Apply priority factor to delay penalty
    priority_factor = PRIORITY_FACTORS.get(job.priority, 1.0)

    return (
        compute * inst.weights['compute_cost']
        + delay * job.delay_weight * inst.weights['delay_penalty'] * priority_factor
    )

def has_capacity_optimized(capacity_usage, server_id, start, duration, req, cached_server_capacity):
    """
    Optimized capacity check using a pre-computed/cached available capacity for the current server.
    """
    for t in range(start, start + duration):
        used = capacity_usage[server_id].get(t, 0)
        available = cached_server_capacity.get(t, 0)
        if used + req > available:
            return False
    return True

# Higher factor means more penalty for waiting

    "Emergency": 0.5, # Very high penalty for Emergency jobs to start late

    "Low": 0.01       # Low penalty for Low priority jobs

    "High": 48,      # Urgent: reasonable horizon
    "Medium": 72,    # Normal: wider search for optimization
    "Low": 96        # Flexible: widest search
}

def operation_objective_improved(inst, server_id, start, op, job, remaining_duration, is_cloud, op_release_time):
    """
    Calculates the objective cost for a given operation, incorporating priority-based
    delay penalties, cloud cost multiplier, and a procrastination penalty.
    """
    compute = sum(inst.server_cost[server_id][t % inst.time_horizon]
                  for t in range(start, start + op.duration))

    if is_cloud:
        compute *= CLOUD_COST_MULTIPLIER

    projected_completion = start + op.duration + remaining_duration
    delay = max(0, projected_completion - job.deadline)

    # Apply priority factor to delay penalty
    priority_factor = PRIORITY_FACTORS.get(job.priority, 1.0)
    delay_penalty = delay * job.delay_weight * priority_factor

    # Procrastination Penalty: Penalize waiting time, scaled by job importance.
    # The wait_time is the difference between actual start and the earliest possible start.
    wait_time = max(0, start - op_release_time)
    procrastination_factor = PROCR_PENALTY_FACTORS.get(job.priority, 0.05)
    procrastination_penalty = wait_time * job.delay_weight * procrastination_factor

    return (
        compute * inst.weights['compute_cost']
        + delay_penalty * inst.weights['delay_penalty']
        + procrastination_penalty # Add this new component
    )
