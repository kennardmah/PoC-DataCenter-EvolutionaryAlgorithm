<ENHANCED_PLACEMENT_HEURISTICS>
This edit refactors the `PlacementEvaluator` class to implement several advanced online scheduling heuristics:

1.  **Non-Linear Load-Balancing Penalty with Capacity Buffer:** The `_calculate_score` method now includes a robust load-balancing penalty for local servers. It uses a cubic term for average utilization over a lookahead window, dramatically increasing the penalty as server congestion rises. Additionally, a new `capacity_buffer_penalty` is introduced, which heavily penalizes placements that would reduce available capacity below a critical threshold (e.g., 10%) at any point during the operation, preventing machines from becoming completely overloaded. This directly addresses Recommendation 1.
2.  **Refined Procrastination Penalty with Slack Awareness:** The procrastination penalty is enhanced to be more dynamic and context-aware, aligning with Recommendation 5. It now considers the job's overall slack (distance to deadline) and amplifies the penalty non-linearly when slack is critically low or negative. This helps to balance immediate cost with future scheduling flexibility.
3.  **Dynamic Heuristic Parameters:** The `__init__` method introduces a comprehensive set of heuristic parameters (`priority_base_horizon`, `priority_procrastination_multiplier`, `cloud_aggressiveness_threshold`, `load_penalty_factor`, `priority_load_multiplier`, `critical_capacity_buffer_ratio`, `capacity_buffer_penalty_magnitude`).
