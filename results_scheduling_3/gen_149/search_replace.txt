<DESCRIPTION>
This edit introduces a "cumulative slack debt" tracker for each job to enhance the procrastination penalty.

Currently, the procrastination penalty for an operation only considers the waiting time for that specific operation. This can lead to myopic decisions where small delays on early operations are not penalized heavily enough, allowing them to cascade and consume all available slack, resulting in significant delays for the final operations.

This change implements the following logic:
1.  **Track Cumulative Debt:** In `schedule_job_online`, a `cumulative_slack_debt` variable is initialized for each job. After each operation is scheduled, the `wait_time` (the difference between its actual start time and its earliest possible start time) is added to this cumulative total.
2.  **Amplify Penalty:** This `cumulative_slack_debt` is passed to the `PlacementDecisionMaker`. Inside the scoring function, the procrastination penalty for the *current* operation is amplified by a factor proportional to the already accumulated debt.

The effect is that if a job's initial operations have already been delayed, the scheduler becomes increasingly "impatient" and penalizes any further waiting for subsequent operations much more harshly. This creates a strong incentive to "catch up" on jobs that are falling behind their ideal schedule, preserving slack for later operations and reducing the risk of large deadline violations. This proactive, history-aware penalty improves the scheduler's foresight within the context of a single job's lifecycle.
</DESCRIPTION>

def schedule_job_online(inst: Instance, job: Job, schedule: Schedule, capacity_usage: Dict[str, Dict[int, int]], current_time: int):
    schedule[job.id] = []
    current_op_release_time = max(job.arrival_time, current_time)
    total_job_duration = sum(op.duration for op in job.operations)

    # Calculate system-wide local load
    total_cap, total_used = 0, 0
    load_window = inst.time_horizon // 2
    for server_id, server in inst.servers.items():
        if not server.is_cloud:
            for t in range(current_time, current_time + load_window):
                total_cap += get_available_capacity(inst, server_id, t)
                total_used += capacity_usage.get(server_id, {}).get(t, 0)
    system_load = total_used / total_cap if total_cap > 0 else 0.0

    urgency_profile = JobUrgencyProfile(inst, job, current_time, total_job_duration, system_load)

    for idx, op in enumerate(job.operations):
        remaining_duration = sum(o.duration for o in job.operations[idx + 1:])
        num_remaining_ops = len(job.operations) - (idx + 1)

        decision_maker = PlacementDecisionMaker(
            inst, job, op, capacity_usage, current_op_release_time,
            remaining_duration, num_remaining_ops, urgency_profile
        )

        chosen_server, chosen_start = decision_maker.find_best_placement()

        # Update shared state
        for t in range(chosen_start, chosen_start + op.duration):
            capacity_usage[chosen_server][t] = capacity_usage[chosen_server].get(t, 0) + op.capacity_required

        schedule[job.id].append({"server": chosen_server, "start": chosen_start})

def schedule_job_online(inst: Instance, job: Job, schedule: Schedule, capacity_usage: Dict[str, Dict[int, int]], current_time: int):
    schedule[job.id] = []
    current_op_release_time = max(job.arrival_time, current_time)
    total_job_duration = sum(op.duration for op in job.operations)
    cumulative_slack_debt = 0.0

    # Calculate system-wide local load
    total_cap, total_used = 0, 0
    load_window = inst.time_horizon // 2
    for server_id, server in inst.servers.items():
        if not server.is_cloud:
            for t in range(current_time, current_time + load_window):
                total_cap += get_available_capacity(inst, server_id, t)
                total_used += capacity_usage.get(server_id, {}).get(t, 0)
    system_load = total_used / total_cap if total_cap > 0 else 0.0

    urgency_profile = JobUrgencyProfile(inst, job, current_time, total_job_duration, system_load)

    for idx, op in enumerate(job.operations):
        remaining_duration = sum(o.duration for o in job.operations[idx + 1:])

            inst, job, op, capacity_usage, current_op_release_time,
