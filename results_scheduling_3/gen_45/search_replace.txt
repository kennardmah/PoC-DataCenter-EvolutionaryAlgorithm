<DESCRIPTION>
This edit refactors the scheduling logic to implement a more sophisticated **Best-Fit** strategy combined with a **procrastination penalty**. This creates a more intelligent trade-off between minimizing compute costs and meeting deadlines.

### Key Changes:

1.  **Best-Fit Search Strategy:** The previous First-Fit logic (`break` statement) is removed. The new algorithm now evaluates *all* available time slots on *all* compatible local machines within a search window. It selects the slot with the absolute lowest cost, allowing it to find cheaper, slightly later slots instead of greedily taking the first one.

2.  **Procrastination Penalty:** A new cost component is added to the objective function (`operation_objective_comprehensive`). This penalty is proportional to the `wait_time` (the time between when an operation *could* start and when it *actually* starts). This penalty is scaled by job priority, strongly discouraging unnecessary delays for high-priority and emergency jobs, even for small cost savings.

3.  **Cloud-First Benchmarking:** Instead of treating cloud and local servers equally in a single loop, the logic now first calculates the cost of using the cheapest available cloud server immediately. This score serves as a **benchmark**. The subsequent best-fit search on local machines only accepts a placement if its score is better than this cloud benchmark, simplifying the decision logic.

4.  **Priority System Bugfix & Enhancement:** The priority factor dictionary keys have been corrected to lowercase (e.g., `"high"`) to match the actual job data, fixing a bug. The system has also been expanded to explicitly handle `"critical"` and `"emergency"` priorities with higher weights, making the scheduler more responsive in crisis scenarios.

Together, these changes create a scheduler that is more cost-aware through best-fit searching, more urgency-aware via the procrastination penalty, and more robust in its decision-making by using the cloud as a clear benchmark.

    "Low": 0.5         # Lower penalty for low priority

CLOUD_COST_MULTIPLIER = 1.5 # Make cloud machines more expensive to encourage local usage

def operation_objective_improved(inst, server_id, start, op, job, remaining_duration, is_cloud):
    """
    Calculates the objective cost for a given operation, incorporating priority-based
    delay penalties and cloud cost multiplier.
    """
    compute = sum(inst.server_cost[server_id][t % inst.time_horizon]
                  for t in range(start, start + op.duration))

    if is_cloud:
        compute *= CLOUD_COST_MULTIPLIER

    projected_completion = start + op.duration + remaining_duration
    delay = max(0, projected_completion - job.deadline)

    # Apply priority factor to delay penalty
    priority_factor = PRIORITY_FACTORS.get(job.priority, 1.0)

    return (
        compute * inst.weights['compute_cost']
        + delay * job.delay_weight * inst.weights['delay_penalty'] * priority_factor
    )

def has_capacity_optimized(capacity_usage, server_id, start, duration, req, cached_server_capacity):
    """
    Optimized capacity check using a pre-computed/cached available capacity for the current server.
    """
    for t in range(start, start + duration):
        used = capacity_usage[server_id].get(t, 0)
        available = cached_server_capacity.get(t, 0)
        if used + req > available:
            return False
    return True

PRIORITY_FACTORS = {
    "emergency": 5.0,
    "critical": 4.0,
    "high": 3.0,
    "medium": 1.5,
    "low": 1.0

PROCRASTINATION_PENALTY_FACTORS = {
    "emergency": 0.8,
    "critical": 0.5,
    "high": 0.2,
    "medium": 0.1,
    "low": 0.05
}
CLOUD_COST_MULTIPLIER = 1.6

def operation_objective_comprehensive(inst, server_id, start, op, job, remaining_duration, is_cloud, op_release_time):
    """
    A comprehensive objective function including compute cost, delay penalty, and procrastination penalty.
    """
    # 1. Compute Cost
    compute = sum(inst.server_cost[server_id][t % inst.time_horizon] for t in range(start, start + op.duration))
    if is_cloud:
        compute *= CLOUD_COST_MULTIPLIER

    # 2. Delay Penalty (how late the job finishes)
    projected_completion = start + op.duration + remaining_duration
    delay = max(0, projected_completion - job.deadline)
    priority_factor = PRIORITY_FACTORS.get(job.priority, 1.0)
    delay_penalty = delay * job.delay_weight * priority_factor

    # 3. Procrastination Penalty (how long we wait to start the operation)
    wait_time = start - op_release_time
    procrastination_factor = PROCRASTINATION_PENALTY_FACTORS.get(job.priority, 0.1)
    procrastination_penalty = wait_time * job.delay_weight * procrastination_factor

    return (
        compute * inst.weights['compute_cost']
        + delay_penalty * inst.weights['delay_penalty']
        + procrastination_penalty
    )
