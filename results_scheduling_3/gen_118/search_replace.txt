<enhance_load_balancing_and_slack>
<DESCRIPTION>
This edit enhances the scheduling logic in `_calculate_operation_score` by introducing more sophisticated load balancing, hotspot avoidance, and multi-operation slack awareness.

1.  **New Parameters:** `critical_utilization_threshold`, `critical_hotspot_penalty_factor`, `hotspot_lookahead_duration`, and `multi_op_slack_penalty_factor` are added to `JobScheduler.__init__` to configure the new load balancing and slack management behaviors.
2.  **Multi-Operation Slack Awareness:** The `procrastination_penalty` is extended to include a `slack_crunch_penalty`. This penalty triggers if scheduling the current operation leaves insufficient slack for subsequent operations of the same job, relative to their combined duration. This encourages proactive scheduling to maintain flexibility for an entire job's sequence.
3.  **Enhanced Load-Balancing and Hotspot Avoidance:**
    *   **Dynamic Lookahead Window:** The load calculation window is refined to span the operation's duration plus a configurable `hotspot_lookahead_duration`. This provides a more forward-looking view of capacity impact.
    *   **Immediate Capacity Check:** An explicit check is added within the load loop: if scheduling the operation would immediately exceed available capacity at any point in the lookahead window, the placement is rejected (`return float('inf')`). This ensures hard constraints are strictly met even for future projected states within the window.
    *   **Non-Linear Base Load Penalty:** The `avg_utilization` is replaced with `(avg_projected_utilization ** 3)` to apply a non-linear (cubic) penalty, which steeply increases as utilization grows. This more aggressively discourages scheduling on already busy local machines.
    *   **Hotspot Penalty:** A distinct `hotspot_penalty` is added. This penalty triggers if the projected utilization in any timestep within the lookahead window exceeds a `critical_utilization_threshold`, strongly penalizing placements that create or exacerbate congestion.
</DESCRIPTION>
