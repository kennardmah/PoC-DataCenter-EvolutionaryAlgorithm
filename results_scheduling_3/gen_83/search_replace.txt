<DESCRIPTION>
This edit redesigns the `QueueCompetitionDispatcher` to implement a more sophisticated and robust online scheduling heuristic. The previous version used a simple "first-available" greedy search for local machines, which is suboptimal as it can lock into locally poor decisions. This new version incorporates several proven operations research techniques to improve decision-making:

1.  **Best-Fit Search with Dynamic Horizon:** Instead of taking the first available slot, the dispatcher now searches for the *best* possible placement within a lookahead window on each local machine. The length of this window (`search_horizon`) is dynamically adjusted based on the job's slack (time to deadline). Urgent jobs get a short window to force quick placement, while jobs with ample slack get a longer window to find more cost-effective slots. This replaces the naive `_find_first_available` method.

2.  **Congestion-Aware Load Balancing:** A new penalty term has been added to the scoring function. It penalizes placing an operation on a local server that is already heavily utilized. The penalty scales quadratically with the server's average utilization, strongly discouraging the creation of "hotspots" and preserving capacity for future high-priority jobs.

3.  **Improved Priority Handling:** The internal dictionary for priority-based wait penalties (`priority_wait_penalty`) has been updated to include `urgent` and `emergency` job types. Furthermore, the lookup is now case-insensitive (`.lower()`) to prevent bugs where job priorities from the data might not match the dictionary's key casing.

4.  **Robust Failsafe:** The logic for finding a placement has been hardened. If the primary "best-fit in window" search fails to find any viable local options (e.g., due to extreme congestion), it falls back to an unbounded search on the cheapest local machine, guaranteeing that a valid schedule is always produced.

These changes transform the dispatcher from a simple greedy algorithm into an intelligent agent that balances cost, delay, and system load, adapting its strategy based on the real-time urgency of each job.

class QueueCompetitionDispatcher:
    """
    Schedules an operation by having cloud and local servers compete.
    Each local server is a "queue" you can wait for; the cloud is an instant option.
    A unified scoring function picks the best choice.
    """
    def __init__(self, inst, job, op, capacity_usage, earliest_start, remaining_duration):
        self.inst = inst
        self.job = job
        self.op = op
        self.capacity_usage = capacity_usage
        self.earliest_start = earliest_start
        self.remaining_duration = remaining_duration
        self.compatible_servers = [
            (s_id, s) for s_id, s in self.inst.servers.items()
            if s.server_type == self.op.server_type
        ]
        # These weights drastically penalize waiting for high-priority jobs.
        self.priority_wait_penalty = {"low": 0.1, "medium": 1.0, "high": 5.0, "critical": 25.0}

    def _calculate_score(self, server_id, start_time):
        """Calculates a holistic score for a placement choice."""
        # 1. Standard cost (compute + delay)
        compute_cost = sum(self.inst.server_cost[server_id].get(t % TIME_HORIZON, 1e6)
                           for t in range(start_time, start_time + self.op.duration))
        projected_completion = start_time + self.op.duration + self.remaining_duration
        delay = max(0, projected_completion - self.job.deadline)
        delay_penalty = delay * self.job.delay_weight

        base_score = (compute_cost * self.inst.weights['compute_cost'] +
                      delay_penalty * self.inst.weights['delay_penalty'])

        # 2. Queuing Cost: Penalty for waiting, scaled by job priority.
        wait_time = start_time - self.earliest_start
        wait_penalty_factor = self.priority_wait_penalty.get(self.job.priority, 1.0)
        queuing_cost = wait_time * self.job.delay_weight * wait_penalty_factor

        # 3. Local Incentive: A small nudge to use local machines if costs are similar.
        local_incentive = 0.0
        if not self.inst.servers[server_id].is_cloud:
            local_incentive = -10.0 # Small bonus for choosing local

        return base_score + queuing_cost + local_incentive

    def _find_first_available(self, server_id):
        """Finds the first available time slot for the op on a server."""
        start_t = self.earliest_start
        # Search forward indefinitely. This guarantees a slot is found.
        while True:
            if has_capacity(self.inst, self.capacity_usage, server_id, start_t, self.op.duration, self.op.capacity_required):
                return start_t
            start_t += 1

    def find_best_placement(self):
        """Evaluates all choices (cloud now vs. wait for local) and picks the best."""
        placement_options = []

        cloud_options = [(s_id, s) for s_id, s in self.compatible_servers if s.is_cloud]
        local_options = [(s_id, s) for s_id, s in self.compatible_servers if not s.is_cloud]

        # 1. Evaluate the "go to cloud immediately" option
        if cloud_options:
            cheapest_cloud_id = min(cloud_options, key=lambda x: self.inst.server_cost[x[0]][self.earliest_start % TIME_HORIZON])[0]
            cloud_score = self._calculate_score(cheapest_cloud_id, self.earliest_start)
            placement_options.append((cloud_score, cheapest_cloud_id, self.earliest_start))

        # 2. Evaluate the "wait in queue" option for each local server
        for server_id, server in local_options:
            available_start = self._find_first_available(server_id)
            local_score = self._calculate_score(server_id, available_start)
            placement_options.append((local_score, server_id, available_start))

        # 3. Handle the case where no compatible servers exist at all
        if not placement_options:
            raise RuntimeError(f"Could not schedule op for job {self.job.id}: No compatible servers found.")

        # 4. Compete and select the best option
        best_score, best_server, best_start = min(placement_options, key=lambda x: x[0])

        return best_server, best_start

class QueueCompetitionDispatcher:
    """
    Schedules an operation by having cloud and local servers compete.
    Local servers perform a best-fit search within a dynamic, slack-bounded horizon.
    A unified scoring function with load-balancing picks the best choice.
    """
    def __init__(self, inst, job, op, capacity_usage, earliest_start, remaining_duration):
        self.inst = inst
        self.job = job
        self.op = op
        self.capacity_usage = capacity_usage
        self.earliest_start = earliest_start
        self.remaining_duration = remaining_duration
        self.compatible_servers = [
            (s_id, s) for s_id, s in self.inst.servers.items()
            if s.server_type == self.op.server_type
        ]
        # These weights drastically penalize waiting for high-priority jobs.
        self.priority_wait_penalty = {"low": 0.1, "medium": 1.0, "high": 5.0, "urgent": 15.0, "critical": 25.0, "emergency": 50.0}
        self.load_penalty_factor = 20.0 # High penalty for congestion

    def _calculate_score(self, server_id, start_time):
        """Calculates a holistic score for a placement choice, including load balancing."""
        server = self.inst.servers[server_id]

        # 1. Standard cost (compute + delay)
        compute_cost = sum(self.inst.server_cost[server_id].get(t % TIME_HORIZON, 1e6)
                           for t in range(start_time, start_time + self.op.duration))
        projected_completion = start_time + self.op.duration + self.remaining_duration
        delay = max(0, projected_completion - self.job.deadline)
        delay_penalty = delay * self.job.delay_weight

        base_score = (compute_cost * self.inst.weights['compute_cost'] +
                      delay_penalty * self.inst.weights['delay_penalty'])

        # 2. Queuing Cost: Penalty for waiting, scaled by job priority.
        wait_time = start_time - self.earliest_start
        wait_penalty_factor = self.priority_wait_penalty.get(self.job.priority.lower(), 1.0) # Case-insensitive
        queuing_cost = wait_time * self.job.delay_weight * wait_penalty_factor

        # 3. Load Balancing Penalty (for local servers)
        load_penalty = 0.0
        if not server.is_cloud:
            utilization_sum = 0
            timesteps = 0
            for t in range(start_time, start_time + self.op.duration):
                used = self.capacity_usage.get(server_id, {}).get(t, 0)
                available = get_available_capacity(self.inst, server_id, t)
                if available > 0:
                    utilization_sum += used / available
                timesteps += 1

            avg_utilization = utilization_sum / timesteps if timesteps > 0 else 0
            # Quadratic penalty makes high utilization very unattractive
            load_penalty = self.load_penalty_factor * (avg_utilization ** 2) * self.job.delay_weight

        # 4. Local Incentive: A small nudge to use local machines if costs are similar.
        local_incentive = -10.0 if not server.is_cloud else 0.0

        return base_score + queuing_cost + load_penalty + local_incentive

    def _get_dynamic_search_horizon(self):
        """Calculates a search window for local machines based on job slack."""
        # Slack is the time between when the job could finish and its deadline
        projected_finish_if_no_wait = self.earliest_start + self.op.duration + self.remaining_duration
        slack = self.job.deadline - projected_finish_if_no_wait

        if slack < self.op.duration:
            return 12  # Critical: short horizon to force an immediate decision
        elif slack < TIME_HORIZON:
            return 48  # Urgent: search a couple of days
        else:
            return 96  # Ample time: long horizon for cost optimization

    def find_best_placement(self):
        """
        Evaluates choices using best-fit in a dynamic window for local, and immediate for cloud.
        Includes a robust failsafe search.
        """
        best_placement = (float('inf'), None, None) # (score, server_id, start_time)

        cloud_options = [(s_id, s) for s_id, s in self.compatible_servers if s.is_cloud]
        local_options = [(s_id, s) for s_id, s in self.compatible_servers if not s.is_cloud]

        # 1. Establish a cloud benchmark if available. This is our "can't be worse than" option.
        if cloud_options:
            cheapest_cloud_id = min(cloud_options, key=lambda x: self.inst.server_cost[x[0]][self.earliest_start % TIME_HORIZON])[0]
            cloud_score = self._calculate_score(cheapest_cloud_id, self.earliest_start)
            best_placement = (cloud_score, cheapest_cloud_id, self.earliest_start)

        # 2. Best-Fit Search: Find the best slot on local machines within the dynamic horizon.
        search_horizon = self._get_dynamic_search_horizon()
        search_end = self.earliest_start + search_horizon

        for server_id, server in local_options:
            for start_t in range(self.earliest_start, search_end):
                if has_capacity(self.inst, self.capacity_usage, server_id, start_t, self.op.duration, self.op.capacity_required):
                    score = self._calculate_score(server_id, start_t)
                    if score < best_placement[0]:
                        best_placement = (score, server_id, start_t)

        # 3. Failsafe: If no placement was found (e.g., local congestion in horizon and no cloud),
        #    find the first available slot on the cheapest local machine, searching indefinitely.
        if best_placement[1] is None and local_options:
            # Find the generally cheapest local server to search on.
            cheapest_local_id = min(local_options, key=lambda x: sum(self.inst.server_cost[x[0]].values()))[0]
            start_t = self.earliest_start
            while True:
                if has_capacity(self.inst, self.capacity_usage, cheapest_local_id, start_t, self.op.duration, self.op.capacity_required):
                    score = self._calculate_score(cheapest_local_id, start_t)
                    best_placement = (score, cheapest_local_id, start_t)
                    break
                start_t += 1

        # 4. Final check for catastrophic failure
        if best_placement[1] is None:
            raise RuntimeError(f"Could not schedule op for job {self.job.id}: No compatible servers found after exhaustive search.")

        _score, best_server, best_start = best_placement
        return best_server, best_start
