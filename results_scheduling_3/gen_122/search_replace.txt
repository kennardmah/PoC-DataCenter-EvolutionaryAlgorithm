<refactor_slack_crunch_and_load_penalty>
Refactored the `_calculate_operation_score` method to explicitly separate a "slack crunch penalty" from the general "procrastination penalty," addressing Recommendation 1 by making this crucial multi-operation slack awareness more distinct and impactful. The penalty now uses a squared ratio for increased aggressiveness when job slack is critically low relative to remaining operations.

Additionally, enhanced the "load-balancing penalty" (Recommendation 2) by increasing the utilization threshold for the quadratic penalty to 80% and making it more aggressive. A new "capacity scarcity penalty" has been introduced within the load penalty calculation. This penalty specifically targets situations where a proposed operation causes the server's *remaining capacity* to fall below a critical threshold (15% of total capacity or half the operation's requirement), proactively avoiding "hotspots" even if overall utilization isn't yet extreme. The lookahead window for load analysis was also extended.

    def _calculate_operation_score(self, server_id: str, start_time: int, op: Operation,
                                   remaining_duration_after_op: int) -> float:
        """Calculates a composite score, incorporating slack crunch, enhanced load-balancing, and local preference."""
        server = self.inst.servers[server_id]

        # 1. Compute Cost
        compute_cost = sum(self.inst.server_cost[server_id][t % self.inst.time_horizon]
                           for t in range(start_time, start_time + op.duration))

        # 2. Delay Penalty
        projected_completion_time = start_time + op.duration + remaining_duration_after_op
        delay = max(0, projected_completion_time - self.job.deadline)
        delay_cost = delay * self.job.delay_weight * self.inst.weights['delay_penalty']

        # 3. Dynamic Procrastination Penalty (Penalty for waiting to start this specific operation)
        wait_time = start_time - self.current_op_start_time
        urgency_multiplier = self.priority_procrastination_multiplier.get(self.job.priority, 1.0)

        # Original slack ratio for procrastination:
        current_slack_for_op_progress = self.job.deadline - (self.current_op_start_time + op.duration + remaining_duration_after_op)
        slack_ratio_procrastination = 1.0
        if current_slack_for_op_progress < 0:
            slack_ratio_procrastination = 1.0 + (math.exp(abs(current_slack_for_op_progress) / (self.inst.time_horizon / 4.0)) - 1.0)
        elif current_slack_for_op_progress < self.inst.time_horizon / 4:
            ratio_to_threshold = (self.inst.time_horizon / 4.0 - current_slack_for_op_progress) / (self.inst.time_horizon / 4.0)
            slack_ratio_procrastination = 1.0 + (ratio_to_threshold**2) * 2.0

        procrastination_penalty = self.base_procrastination_penalty_factor \
                                * wait_time \
                                * urgency_multiplier * slack_ratio_procrastination

        # 4. Multi-Operation Slack Crunch Penalty (Recommendation 1)
        slack_crunch_penalty = 0.0
        if remaining_duration_after_op > 0: # Only applies if there are subsequent operations
            # Slack for the *entire remaining job* after this operation finishes
            job_remaining_total_duration = op.duration + remaining_duration_after_op
            job_projected_finish_time = start_time + job_remaining_total_duration

            # This is the available slack *after* this operation and all subsequent ops
            remaining_job_slack_at_deadline = self.job.deadline - job_projected_finish_time

            # If slack is getting critically low relative to remaining operations duration
            # E.g., if remaining slack is less than 50% of the duration of subsequent ops
            critical_slack_threshold = remaining_duration_after_op * 0.5
            if remaining_job_slack_at_deadline < critical_slack_threshold:
                # The penalty increases quadratically as slack diminishes towards zero or becomes negative
                # Scale by job's delay weight to ensure high-penalty jobs are more sensitive
                slack_deficiency = critical_slack_threshold - remaining_job_slack_at_deadline
                slack_crunch_penalty = (slack_deficiency / self.inst.time_horizon)**2 * 50.0 * self.job.delay_weight
                slack_crunch_penalty *= urgency_multiplier # More urgent jobs get higher penalty


        # 5. Enhanced Non-Linear Hotspot Avoidance Load Balancing Penalty (Recommendation 2)
        load_penalty = 0.0
        if not server.is_cloud:
            # Extended lookahead window for better anticipation of congestion
            window_start = max(0, start_time - op.duration) # Look back
            window_end = start_time + op.duration + TIME_HORIZON // 2 # Look ahead up to TIME_HORIZON/2 (e.g., 12 hours)

            for t in range(window_start, window_end):
                used_at_t = self.capacity_usage.get(server.id, {}).get(t, 0)
                available_at_t = get_available_capacity(self.inst, server.id, t)

                # Capacity Scarcity Penalty (Hotspot Avoidance)
                # Penalize heavily if this operation makes capacity critically scarce
                current_remaining_capacity = available_at_t - used_at_t
                if current_remaining_capacity < op.capacity_required * 1.5: # E.g., less than 1.5x operation capacity needed
                    # If placing this operation makes remaining capacity too low (e.g., < 15% of total or even negative)
                    critical_capacity_threshold = max(self.inst.servers[server.id].capacity * 0.15, op.capacity_required * 0.5)
                    if (current_remaining_capacity - op.capacity_required) < critical_capacity_threshold:
                        scarcity_amount = critical_capacity_threshold - (current_remaining_capacity - op.capacity_required)
                        # Exponentially increasing penalty for severe scarcity
                        load_penalty += math.exp(scarcity_amount / (self.inst.servers[server.id].capacity * 0.1)) * self.capacity_scarcity_penalty_factor


                # Non-Linear Utilization Penalty (Above 80% utilization)
                if available_at_t > 0:
                    projected_utilization = (used_at_t + op.capacity_required) / available_at_t
                    if projected_utilization > 0.8: # Kicks in aggressively above 80% utilization
                        load_penalty += (projected_utilization - 0.8)**2 * self.load_penalty_factor * 20.0 # Aggressive quadratic increase

            load_prio_mult = self.priority_load_multiplier.get(self.job.priority, 1.0)
            load_penalty *= load_prio_mult * self.job.delay_weight # Scale by job priority and delay_weight


        # Combine all cost components
        total_score = (compute_cost * self.inst.weights['compute_cost'] +
                       delay_cost + procrastination_penalty + slack_crunch_penalty + load_penalty)

        return total_score
