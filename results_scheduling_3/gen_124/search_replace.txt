<DESCRIPTION>
The current `PlacementEvaluator` class represents a significant step back from previously successful, more sophisticated scheduling models. Its simplistic scoring and first-fit local search strategy fail to adequately handle the complex trade-offs of this problem, resulting in a poor score.

This edit replaces the entire evolvable block with a new `JobScheduler` class that reintroduces and refines the powerful heuristics from the best-performing prior generations. This comprehensive change is designed to recover from the performance regression and improve resilience, especially in the earthquake scenario.

Key features of the new `JobScheduler`:

1.  **Multi-Component Scoring Function:** The core of the scheduler is a sophisticated `_calculate_operation_score` method that evaluates placements based on four weighted factors:
    *   **Compute Cost & Delay Penalty:** The fundamental objective components.
    *   **Dynamic Procrastination Penalty:** A crucial heuristic that heavily penalizes delaying the start of an operation, especially for high-priority jobs or those with little remaining slack time. The penalty scales non-linearly, making the scheduler extremely sensitive to impending deadline breaches.
    *   **Load-Balancing Penalty:** To prevent local machine congestion, a penalty is applied based on the server's utilization in a time window around the proposed operation. This encourages distributing the workload, which is vital for maintaining performance when local capacity is reduced during the earthquake.

2.  **Best-Fit Local Search:** Instead of greedily taking the first available slot, `_find_best_local_placement` performs a "best-fit" search. It evaluates *all* potential start times for an operation across *all* compatible local machines within a dynamic search horizon, selecting the placement with the lowest overall score.

3.  **Adaptive Heuristics:** The scheduler's behavior is dynamically adapted to each job's specific needs:
    *   **Dynamic Search Horizon:** The time window for the local search is adjusted based on job priority and slack—shorter for urgent jobs to find a solution quickly, and longer for non-urgent jobs to find a cheaper solution.
    *   **Priority-Driven Cloud Aggressiveness:** A `cloud_aggressiveness_threshold`, tuned per priority level, governs the local vs. cloud decision. This pushes critical and emergency jobs towards the guaranteed availability of the cloud unless a significantly better local option is immediately available.

4.  **Explicit Emergency Handling:** All heuristic parameter dictionaries now include an `emergency` priority level with aggressive tuning to ensure that jobs arriving during the earthquake scenario are treated with the highest urgency, prioritizing speed and resilience over cost.

class PlacementEvaluator:
    """A service to find the best placement for a single operation."""

    def __init__(self, inst, job, op, capacity_usage, earliest_start, remaining_duration):
        self.inst = inst
        self.job = job
        self.op = op
        self.capacity_usage = capacity_usage
        self.earliest_start = earliest_start
        self.remaining_duration = remaining_duration
        self.compatible_servers = [
            (s_id, s) for s_id, s in self.inst.servers.items()
            if s.server_type == self.op.server_type
        ]

    def _calculate_score(self, server_id, start_time):
        """Calculates the objective score for a given placement."""
        compute = sum(self.inst.server_cost[server_id].get(t % TIME_HORIZON, 1e6)
                      for t in range(start_time, start_time + self.op.duration))

        projected_completion = start_time + self.op.duration + self.remaining_duration
        delay = max(0, projected_completion - self.job.deadline)

        delay_penalty = delay * self.job.delay_weight

        # Add a penalty for waiting, proportional to the job's delay sensitivity.
        wait_time = start_time - self.earliest_start
        procrastination_penalty = wait_time * self.job.delay_weight * 0.1

        return (compute * self.inst.weights['compute_cost'] +
                delay_penalty * self.inst.weights['delay_penalty'] +
                procrastination_penalty)

    def _find_first_available(self, server_id, max_search_horizon):
        """Finds the first available time slot for an operation on a server."""
        for start_t in range(self.earliest_start, self.earliest_start + max_search_horizon):
            if has_capacity(self.inst, self.capacity_usage, server_id, start_t, self.op.duration, self.op.capacity_required):
                return start_t
        return None

    def find_best_placement(self):
        """
        Evaluates local and cloud options to find the optimal placement.
        Uses a cloud benchmark to decide if waiting for a local machine is worth it.
        """
        best_placement = (float('inf'), None, None) # (score, server_id, start_time)

        cloud_options = [(s_id, s) for s_id, s in self.compatible_servers if s.is_cloud]
        local_options = [(s_id, s) for s_id, s in self.compatible_servers if not s.is_cloud]

        # 1. Establish a cloud benchmark: cost of scheduling immediately on the cheapest cloud server.
        if cloud_options:
            cheapest_cloud_id = min(cloud_options, key=lambda x: self.inst.server_cost[x[0]][self.earliest_start % TIME_HORIZON])[0]
            cloud_benchmark_score = self._calculate_score(cheapest_cloud_id, self.earliest_start)
            best_placement = (cloud_benchmark_score, cheapest_cloud_id, self.earliest_start)

        # 2. Evaluate local machines: find first available slot and compare its score to the cloud benchmark.
        priority_map = {"low": 48, "medium": 24, "high": 12, "critical": 6}
        search_horizon = priority_map.get(self.job.priority, 24)

        for server_id, server in local_options:
            available_start = self._find_first_available(server_id, search_horizon)
            if available_start is not None:
                local_score = self._calculate_score(server_id, available_start)
                if local_score < best_placement[0]:
                    best_placement = (local_score, server_id, available_start)

        # 3. Failsafe: If no placement was found, perform an exhaustive search on the cheapest local machine.
        if best_placement[1] is None and local_options:
            cheapest_local_id = min(local_options, key=lambda x: sum(self.inst.server_cost[x[0]].values()))[0]

            start_t = self.earliest_start
            while True: # Search indefinitely
                if has_capacity(self.inst, self.capacity_usage, cheapest_local_id, start_t, self.op.duration, self.op.capacity_required):
                    score = self._calculate_score(cheapest_local_id, start_t)
                    best_placement = (score, cheapest_local_id, start_t)
                    break
                start_t += 1

        if best_placement[1] is None:
             raise RuntimeError(f"Could not schedule op for job {self.job.id}")

        return best_placement[1], best_placement[2]

class JobScheduler:
    def __init__(self, inst: Instance, job: Job,
                 schedule: Schedule, capacity_usage: Dict[str, Dict[int, int]],
                 current_system_time: int):
        self.inst = inst
        self.job = job
        self.schedule = schedule
        self.capacity_usage = capacity_usage
        self.current_op_start_time = max(job.arrival_time, current_system_time)
        self.scheduled_job_ops = []

        # --- Heuristic Parameters ---
        self.priority_base_horizon = {'emergency': 4, 'critical': 6, 'urgent': 12, 'high': 24, 'medium': 48, 'low': 72}
        self.priority_procrastination_multiplier = {'emergency': 10.0, 'critical': 8.0, 'urgent': 4.0, 'high': 2.0, 'medium': 1.0, 'low': 0.5}
        self.base_procrastination_penalty_factor = 0.05
        self.cloud_aggressiveness_threshold = {'emergency': 0.9, 'critical': 1.2, 'urgent': 1.1, 'high': 1.0, 'medium': 0.95, 'low': 0.9}
        self.load_penalty_factor = 5.0
        self.priority_load_multiplier = {"emergency": 5.0, "critical": 2.0, "urgent": 2.5, "high": 1.5, "medium": 1.0, "low": 0.5}


    def _calculate_operation_score(self, server_id: str, start_time: int, op: Operation,
                                   remaining_duration_after_op: int) -> float:
        """Calculates a composite score, incorporating load-balancing and local preference."""
        server = self.inst.servers[server_id]

        # 1. Compute Cost
        compute_cost = sum(self.inst.server_cost[server_id][t % self.inst.time_horizon]
                           for t in range(start_time, start_time + op.duration))

        # 2. Delay Penalty
        projected_completion_time = start_time + op.duration + remaining_duration_after_op
        delay = max(0, projected_completion_time - self.job.deadline)
        delay_cost = delay * self.job.delay_weight * self.inst.weights['delay_penalty']

        # 3. Dynamic Procrastination Penalty
        current_slack_for_op = self.job.deadline - (self.current_op_start_time + op.duration + remaining_duration_after_op)
        urgency_multiplier = self.priority_procrastination_multiplier.get(self.job.priority, 1.0)

        slack_ratio = 1.0
        if current_slack_for_op < 0:
            slack_ratio = 1.0 + (math.exp(abs(current_slack_for_op) / (self.inst.time_horizon / 4.0)) - 1.0)
        elif current_slack_for_op < self.inst.time_horizon / 4:
            ratio_to_threshold = (self.inst.time_horizon / 4.0 - current_slack_for_op) / (self.inst.time_horizon / 4.0)
            slack_ratio = 1.0 + (ratio_to_threshold**2) * 2.0

        procrastination_penalty = self.base_procrastination_penalty_factor \
                                * (start_time - self.current_op_start_time) \
                                * urgency_multiplier * slack_ratio

        # 4. Load-Balancing Penalty
        load_penalty = 0.0
        if not server.is_cloud:
            window_start = max(0, start_time - op.duration)
            window_end = start_time + op.duration * 2
            total_utilization, num_timesteps = 0.0, 0
            for t in range(window_start, window_end):
                used = self.capacity_usage.get(server_id, {}).get(t, 0)
                available = get_available_capacity(self.inst, server_id, t)
                if available > 0:
                    total_utilization += used / available
                num_timesteps += 1
            if num_timesteps > 0:
                avg_utilization = total_utilization / num_timesteps
                load_prio_mult = self.priority_load_multiplier.get(self.job.priority, 1.0)
                load_penalty = avg_utilization * self.load_penalty_factor * load_prio_mult * self.job.delay_weight

        # Combine all cost components
        total_score = (compute_cost * self.inst.weights['compute_cost'] +
                       delay_cost + procrastination_penalty + load_penalty)

        return total_score

    def _find_best_cloud_placement(self, op: Operation, remaining_duration_after_op: int) -> Optional[tuple]:
        """Finds the cheapest immediate cloud placement."""
        best_score, best_server_id = float('inf'), None
        for server_id, server in self.inst.servers.items():
            if server.server_type == op.server_type and server.is_cloud:
                score = self._calculate_operation_score(server_id, self.current_op_start_time, op, remaining_duration_after_op)
                if score < best_score:
                    best_score, best_server_id = score, server_id
        return (best_score, best_server_id, self.current_op_start_time) if best_server_id else None

    def _find_best_local_placement(self, op: Operation, remaining_duration_after_op: int) -> Optional[tuple]:
        """Finds the best local placement (server, start_time) within a dynamic horizon."""
        best_score, best_placement = float('inf'), None

        total_rem_dur = op.duration + remaining_duration_after_op
        current_slack = self.job.deadline - (self.current_op_start_time + total_rem_dur)
        base_horizon = self.priority_base_horizon.get(self.job.priority, 32)
        slack_multiplier = max(0.25, min(3.0, 1.0 + (current_slack / self.inst.time_horizon / 2.0)))
        search_horizon = max(op.duration, int(base_horizon * slack_multiplier))
        search_limit = self.current_op_start_time + search_horizon

        for server_id, server in self.inst.servers.items():
            if server.server_type == op.server_type and not server.is_cloud:
                for start in range(self.current_op_start_time, search_limit + 1):
                    if has_capacity(self.inst, self.capacity_usage, server_id, start, op.duration, op.capacity_required):
                        score = self._calculate_operation_score(server_id, start, op, remaining_duration_after_op)
                        if score < best_score:
                            best_score, best_placement = score, (score, server_id, start)
        return best_placement

    def schedule_all_operations(self):
        """Schedules all operations for the job, making decisions for each op."""
        for idx, op in enumerate(self.job.operations):
            remaining_duration_after_op = sum(o.duration for o in self.job.operations[idx + 1:])

            cloud_res = self._find_best_cloud_placement(op, remaining_duration_after_op)
            local_res = self._find_best_local_placement(op, remaining_duration_after_op)

            cloud_score = cloud_res[0] if cloud_res else float('inf')
            local_score = local_res[0] if local_res else float('inf')

            chosen_server, chosen_start = None, -1
            cloud_pref_factor = self.cloud_aggressiveness_threshold.get(self.job.priority, 1.0)

            if local_res and local_score < (cloud_score * cloud_pref_factor):
                chosen_server, chosen_start = local_res[1], local_res[2]
            elif cloud_res:
                chosen_server, chosen_start = cloud_res[1], cloud_res[2]
            else: # Failsafe logic
                compatible_servers = [s for s in self.inst.servers.values() if s.server_type == op.server_type]
                if any(s.is_cloud for s in compatible_servers):
                    cheapest_cloud = min((s for s in compatible_servers if s.is_cloud),
                                         key=lambda s: self.inst.server_cost[s.id][self.current_op_start_time % self.inst.time_horizon])
                    chosen_server, chosen_start = cheapest_cloud.id, self.current_op_start_time
                else:
                    cheapest_local = min((s for s in compatible_servers if not s.is_cloud),
                                         key=lambda s: sum(self.inst.server_cost[s.id].values()))
                    start_t = self.current_op_start_time
                    while True:
                        if has_capacity(self.inst, self.capacity_usage, cheapest_local.id, start_t, op.duration, op.capacity_required):
                            chosen_server, chosen_start = cheapest_local.id, start_t
                            break
                        start_t += 1

            for t in range(chosen_start, chosen_start + op.duration):
                self.capacity_usage[chosen_server][t] = self.capacity_usage[chosen_server].get(t, 0) + op.capacity_required

            self.scheduled_job_ops.append({"server": chosen_server, "start": chosen_start})
            self.current_op_start_time = chosen_start + op.duration

        self.schedule[self.job.id] = self.scheduled_job_ops
