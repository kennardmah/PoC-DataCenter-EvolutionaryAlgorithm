<DESCRIPTION>
This edit proposes two targeted improvements to the scheduling heuristic to enhance placement decisions:

1.  **Corrected Load Penalty Calculation**: The load-balancing penalty in `PlacementDecisionMaker._calculate_operation_score` is corrected. The original code incorrectly added the current operation's capacity requirement to the utilization calculation for the entire lookahead window, even for time steps *after* the operation would have completed. This overestimated future load and could lead to suboptimal decisions. The logic is fixed to only add the operation's capacity requirement for the time steps during its actual execution, making the hotspot avoidance heuristic more accurate and reliable.

2.  **Best-Fit Local Search**: The local placement search logic in `PlacementDecisionMaker.find_best_placement` is changed from a variant of "first-fit" to a comprehensive "best-fit". The original implementation would evaluate only the first available time slot on each local server before moving to the next. By removing the `break` statement, the algorithm now evaluates *all* available time slots within the dynamic search horizon for *all* compatible local servers. This enables it to discover potentially much better placements that might occur slightly later but offer lower compute costs or avoid congestion. This more thorough search increases the quality of local placement candidates.
</DESCRIPTION>
