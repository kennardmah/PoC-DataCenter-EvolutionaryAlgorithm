<DESCRIPTION>
This edit significantly refactors the `schedule_job_online` function to incorporate several key heuristic improvements:

1.  **Operation-Level Local Search Window (Recommendation 1)**: For local machines, instead of simply taking the *first* available slot, the scheduler now searches within a `MAX_LOCAL_SEARCH_WINDOW` (2 full time horizons + 12 hours) to find the *best* available slot that minimizes the total cost. This allows for a more optimal placement on local resources, balancing immediate availability with better cost/delay profiles further in the future.

2.  **Integrated Explicit Cloud Deterrence (Recommendation 2)**: A `CLOUD_DETERRENCE_BASE` penalty is now explicitly added to the compute cost when an operation is scheduled on a cloud server. This encourages the scheduler to prefer cheaper local machines unless the cost/delay on local resources is significantly worse.

3.  **Priority-Weighted Delay Multipliers (Recommendation 5)**: A `PRIORITY_MULTIPLIERS` dictionary is introduced to apply different weights to the delay penalty based on job priority (`emergency`, `high`, `medium`, `low`). This ensures that high-priority and emergency jobs are penalized more severely for delays, pushing the scheduler to prioritize their timely completion.

4.  **Dynamic Cloud Deterrence for Emergency Jobs**: The `CLOUD_EMERGENCY_DISCOUNT` is applied to reduce the cloud deterrence for 'emergency' jobs. This makes cloud resources a more attractive and viable option for critical tasks that must be completed quickly, even at a higher base cost.

These features are implemented within a new, internal helper function `_calculate_placement_score` to centralize the objective calculation logic, making the main scheduling loop cleaner and more readable. This prepares the code for future enhancements like conditional cloud fallback (Recommendation 4) by making the cloud deterrence parameter dynamically modifiable.

def schedule_job_online(inst: Instance,
                        job: Job,
                        schedule: Schedule,
                        capacity_usage: Dict[str, Dict[int, int]],
                        current_time: int):

    # Define parameters for the scheduling heuristic
    PRIORITY_MULTIPLIERS = {
        'emergency': 8.0, # High priority, severe penalty for delay
        'high': 3.0,
        'medium': 1.0,
        'low': 0.5,       # Lower priority, more flexible with delay
    }
    CLOUD_DETERRENCE_BASE = 75.0 # Base cost to deter cloud usage
    CLOUD_EMERGENCY_DISCOUNT = 0.8 # Reduce cloud deterrence for emergency jobs
    MAX_LOCAL_SEARCH_WINDOW = inst.time_horizon * 2 + 12 # Search up to 60 hours for local machines

    # Helper function to calculate the score for a proposed operation placement
    def _calculate_placement_score(
        _inst: Instance,
        _job: Job,
        _operation: Operation,
        _proposed_start: int,
        _server_id: str,
        _is_cloud_server: bool,
        _remaining_ops_duration: int,
        _priority_multipliers: Dict[str, float],
        _cloud_deterrence_base: float,
        _cloud_emergency_discount: float
    ) -> float:
        """
        Calculates a weighted score for a proposed operation placement,
        considering compute cost, the impact on the job's overall delay penalty,
        and adding dynamic cloud deterrence.
        """
        # Compute cost for THIS operation
        op_compute_cost = sum(_inst.server_cost[_server_id][t % _inst.time_horizon]
                              for t in range(_proposed_start, _proposed_start + _operation.duration))

        # Add cloud deterrence if the operation is placed on a cloud server.
        if _is_cloud_server:
            deterrence = _cloud_deterrence_base
            if _job.priority == 'emergency':
                deterrence *= (1.0 - _cloud_emergency_discount)
            op_compute_cost += deterrence

        # Projected completion time for THE ENTIRE JOB
        projected_op_end = _proposed_start + _operation.duration
        projected_job_completion = projected_op_end + _remaining_ops_duration

        # Delay penalty for THE ENTIRE JOB
        delay = max(0, projected_job_completion - _job.deadline)

        # Apply priority multiplier to delay penalty
        priority_factor = _priority_multipliers.get(_job.priority, 1.0)
        delay_penalty = delay * _job.delay_weight * priority_factor * _inst.weights['delay_penalty']

        # Total score for this specific operation placement
        total_score = (
            op_compute_cost * _inst.weights['compute_cost']
            + delay_penalty
        )

        # Tie-breaker: prefer earlier starts slightly if costs are otherwise equal
        total_score += _proposed_start * 0.0001

        return total_score

    schedule[job.id] = []
    op_start_time_predecessor = max(job.arrival_time, current_time)

    for idx, op in enumerate(job.operations):
        remaining_operations_duration = sum(o.duration for o in job.operations[idx + 1:])

        best_score = float('inf')
        chosen_server_id = None
        chosen_start_time = None

        # --- Evaluate ALL Options (Local and Cloud) to find the absolute best ---
        # This structure allows direct comparison between the best local and best cloud options.
        for server_id, server in inst.servers.items():
            if server.server_type != op.server_type:
                continue

            if server.is_cloud:
                # Cloud: always available immediately after predecessor completes
                proposed_start = op_start_time_predecessor
                score = _calculate_placement_score(
                    inst, job, op, proposed_start, server_id, True, # Pass True for _is_cloud_server
                    remaining_operations_duration, PRIORITY_MULTIPLIERS,
                    CLOUD_DETERRENCE_BASE, CLOUD_EMERGENCY_DISCOUNT # Pass cloud deterrence parameters
                )
                if score < best_score:
                    best_score = score
                    chosen_server_id = server_id
                    chosen_start_time = proposed_start
            else:
                # Local: search for the BEST available slot within the search window
                search_end_time = min(job.deadline + inst.time_horizon,
                                      op_start_time_predecessor + MAX_LOCAL_SEARCH_WINDOW)

                for proposed_start in range(op_start_time_predecessor, search_end_time + 1):
                    if has_capacity(inst, capacity_usage, server_id, proposed_start, op.duration, op.capacity_required):
                        score = _calculate_placement_score(
                            inst, job, op, proposed_start, server_id, False, # Pass False for _is_cloud_server
                            remaining_operations_duration, PRIORITY_MULTIPLIERS,
                            CLOUD_DETERRENCE_BASE, CLOUD_EMERGENCY_DISCOUNT # Pass cloud deterrence parameters
                        )
                        if score < best_score:
                            best_score = score
                            chosen_server_id = server_id
                            chosen_start_time = proposed_start
                        # Continue searching to find the *best* local slot, not just the first.

        # --- Final Selection and Capacity Reservation ---
        if chosen_server_id is None:
            # Fallback for robustness: assign to *any* compatible cloud server
            # This should only be reached if there's a serious configuration issue
            # where no local or cloud options were found.
            for server_id, server in inst.servers.items():
                if server.is_cloud and server.server_type == op.server_type:
                    chosen_server_id = server_id
                    chosen_start_time = op_start_time_predecessor
                    break
            if chosen_server_id is None:
                raise Exception(f"Could not schedule operation {idx} for job {job.id}: No compatible server (local or cloud) found after exhaustive search.")


        # Reserve capacity for the chosen operation

            capacity_usage[chosen_server_id][t] = capacity_usage[chosen_server_id].get(t, 0) + op.capacity_required

        # Add to job's schedule
        schedule[job.id].append({"server": chosen_server_id, "start": chosen_start_time})

        op_start_time_predecessor = chosen_start_time + op.duration
