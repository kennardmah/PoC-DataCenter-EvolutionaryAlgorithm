<DESCRIPTION>
This edit refines the objective function by implementing a dynamic cloud deterrence mechanism and further tuning priority multipliers.

1.  **Dynamic Cloud Deterrence**: The previous fixed `CLOUD_DETERRENCE_BASE` is replaced with `CLOUD_DETERRENCE_RATE_PER_UNIT_DURATION`. This makes the cloud penalty scale proportionally to the duration of the operation, providing a more granular and realistic cost representation for using cloud resources. This directly addresses Recommendation 2 (cloud cost deterrence) by making it more effective based on resource usage.
2.  **Tuned Priority Multipliers**: The `PRIORITY_MULTIPLIERS` for 'emergency' and 'high' priority jobs are further increased. This makes delays for these critical jobs even more costly, encouraging the scheduler to prioritize their completion more aggressively, potentially leveraging cloud resources when local capacity is constrained. This aligns with Recommendation 2 for enhancing objective function with dynamic priority multipliers.
