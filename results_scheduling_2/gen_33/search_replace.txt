<standardized_cloud_deterrence>
This edit standardizes and refines the cloud deterrence calculation within the objective function, explicitly incorporating job priority scaling.

Key changes:
1.  **Renamed Constant**: `CLOUD_DETERRENCE_RATE_PER_UNIT_DURATION` is renamed to `CLOUD_BASE_DETERRENCE_PER_UNIT_DURATION` for improved clarity.
2.  **Priority-Scaled Cloud Deterrence**: The base cloud deterrence cost is now explicitly multiplied by the `priority_factor`. This means higher-priority jobs will incur a proportionally higher penalty for using cloud resources, aligning the cloud cost more directly with the job's overall importance, as suggested by the "Priority-Weighted Objective Functions" pattern.
3.  **Emergency Discount Preservation**: The `CLOUD_EMERGENCY_DISCOUNT_FACTOR` is still applied to emergency jobs *after* the priority scaling, ensuring that critical jobs still receive a reduced cloud penalty when necessary.
4.  **Tuned Constant**: The `CLOUD_BASE_DETERRENCE_PER_UNIT_DURATION` is slightly increased from 25.0 to 35.0 to encourage stronger preference for local resources, as per the spirit of previous recommendations.
5.  **Clarity in Cost Calculation**: `op_compute_cost_raw` is introduced to clearly separate the raw compute cost from the added cloud deterrence, making the cost components more transparent.

This change aims to provide a more consistent and strategically aligned cost model for cloud usage, where resource allocation decisions are better informed by both monetary cost and job urgency.
