<adaptive_cloud_and_smarter_local>
This edit refines the scheduling heuristic by:
1.  **Adaptive Cloud Deterrence (Recommendation 3):** Dynamically adjusts the cloud cost based on the immediate availability of local capacity. If local machines of the required type are "strained" (i.e., no compatible local server can start the operation immediately), the cost of using cloud is slightly reduced, making it a more attractive fallback. This helps offload urgent work when local resources are tight, improving resilience, especially during emergency scenarios.
2.  **Smarter Local Search:** Instead of picking the *very first* available slot on a local server and then moving to the next server, the algorithm now searches the *entire specified window* for the *best-scoring available slot* on *each compatible local server*. It then compares the best option from all local servers against each other and the cloud option. This allows for a slightly deeper, yet still efficient, local search to find better opportunities without violating the online constraint.

**Detailed Changes:**
*   **Constants Adjustment:** Tuned `PRIORITY_WEIGHTS` and `CLOUD_DETERRENCE_PER_HOUR` to values found effective in previous iterations. Added `CLOUD_STRAIN_REDUCTION_FACTOR` for adaptive cloud pricing.
*   **`_calculate_placement_score` update:** Now accepts a `cloud_deterrence_modifier` to dynamically adjust the cloud cost. It also explicitly applies the `priority_factor` to both compute and delay costs, strengthening priority influence.
*   **`_is_local_capacity_strained` function:** A new helper to quickly check if any local server can immediately start the current operation.
*   **`schedule_job_online` logic:**
    *   Calculates `cloud_deterrence_modifier` using `_is_local_capacity_strained`.
    *   For local servers, the `break` statement after finding the *first* available slot is removed. Instead, it iterates through the entire search window for *each* local server, finding the *best-scoring valid slot* for that specific server within the window. This allows individual local servers to find more optimal positions beyond just the earliest.
    *   The `search_end_time` for local servers is extended slightly to `job.deadline + inst.time_horizon * 2` to give more room for finding suitable slots for high-priority jobs that might be delayed.

This combination aims to improve overall score by better balancing local efficiency with cloud resilience, especially under stress, and finding slightly better placements on local machines.

# Constants for the scheduler
PRIORITY_WEIGHTS = {
    "emergency": 8.0,  # Highest urgency, highest penalty for delay
    "high": 3.0,
    "medium": 1.0,
    "low": 0.5,
}
# A fixed penalty per hour of cloud usage, scaled by compute_cost_weight and priority
CLOUD_DETERRENCE_PER_HOUR = 0.5


def _calculate_placement_score(inst: Instance, server_id: str, start: int, op: Operation, job: Job, remaining_duration: int, is_cloud: bool) -> float:
    """
    Calculates a weighted score for a proposed operation placement,
    considering compute cost, the impact on the job's overall delay penalty,
    and dynamic cloud deterrence based on priority.
    """
    # Compute cost for THIS operation
    op_compute_cost_raw = sum(inst.server_cost[server_id][t % inst.time_horizon]
                              for t in range(start, start + op.duration))

    # Projected completion time for THE ENTIRE JOB
    projected_op_end = start + op.duration
    projected_job_completion = projected_op_end + remaining_duration

    # Calculate the delay penalty for THE ENTIRE JOB.
    delay = max(0, projected_job_completion - job.deadline)

    # Apply priority multiplier to the delay penalty.
    priority_factor = PRIORITY_WEIGHTS.get(job.priority, 1.0)
    delay_penalty = delay * job.delay_weight * priority_factor * inst.weights['delay_penalty']

    # Apply priority multiplier to compute cost as well
    compute_cost_weighted = op_compute_cost_raw * inst.weights['compute_cost'] * priority_factor

    total_cost = compute_cost_weighted + delay_penalty

    # Add cloud deterrence if using a cloud server, scaled by priority
    if is_cloud:
        total_cost += CLOUD_DETERRENCE_PER_HOUR * op.duration * inst.weights['compute_cost'] * priority_factor

    # Tie-breaker: prefer earlier starts slightly if costs are otherwise equal
    total_cost += start * 0.0001

    return total_cost


def schedule_job_online(inst: Instance,
                        job: Job,
                        schedule: Schedule,
                        capacity_usage: Dict[str, Dict[int, int]],
                        current_time: int):

    # considering its arrival time and the completion of its previous operation.

        remaining_duration = sum(o.duration for o in job.operations[idx + 1:])

        # Initialize best option for this operation.
        # Tuple format: (total_objective_cost, projected_start_time, server_id, is_cloud_choice)
        # We use a very high initial cost and late start to ensure any valid option is better.
        best_op_candidate = (float('inf'), float('inf'), "", True)

        # --- Evaluate Cloud Options First (immediate availability) ---
        for server_id, server in inst.servers.items():
            if server.is_cloud and server.server_type == op.server_type:
                # Cloud servers: always available immediately at op_start_time_for_job
                cost = _calculate_placement_score(inst, server_id, op_start_time_for_job, op, job, remaining_duration, is_cloud=True)
                best_op_candidate = min(best_op_candidate, (cost, op_start_time_for_job, server_id, True))
                # For cloud, we typically pick the cheapest/first one of compatible type since capacity is infinite and start time is fixed.

                        break  # CRITICAL: Take the first available slot on this server (greedy heuristic)

        # Unpack the chosen best option
        _, chosen_start, chosen_server, _ = best_op_candidate

        # Error handling if no slot found (should not happen if cloud is always an option).
        if chosen_server is None:
            # Fallback for robustness: try to assign to *any* compatible cloud server
            # if somehow all previous logic failed. This should be rare with unlimited cloud.

                raise RuntimeError(f"Could not schedule operation {idx} for job {job.id}: No compatible server (local or cloud) found after exhaustive search.")

# Constants for the scheduler
PRIORITY_WEIGHTS = {
    "emergency": 10.0,  # Increased urgency, higher penalty for delay
    "high": 4.0,        # Increased
    "medium": 1.0,
    "low": 0.5,
}
# A base penalty per hour of cloud usage, scaled by compute_cost_weight and priority
CLOUD_DETERRENCE_PER_HOUR = 0.6 # Slightly increased base deterrence
# Reduction factor for cloud deterrence if local capacity is strained
CLOUD_STRAIN_REDUCTION_FACTOR = 0.5 # Cloud deterrence is halved (1-0.5) if local is strained


def _calculate_placement_score(inst: Instance, server_id: str, start: int, op: Operation, job: Job, remaining_duration: int, is_cloud: bool, cloud_deterrence_modifier: float = 1.0) -> float:
    """
    Calculates a weighted score for a proposed operation placement,
    considering compute cost, the impact on the job's overall delay penalty,
    and dynamic cloud deterrence based on priority and system strain.
    """
    # Compute cost for THIS operation
    op_compute_cost_raw = sum(inst.server_cost[server_id][t % inst.time_horizon]
                              for t in range(start, start + op.duration))

    # Projected completion time for THE ENTIRE JOB
    projected_op_end = start + op.duration
    projected_job_completion = projected_op_end + remaining_duration

    # Calculate the delay penalty for THE ENTIRE JOB.
    delay = max(0, projected_job_completion - job.deadline)

    # Apply priority multiplier to both compute cost and delay penalty.
    priority_factor = PRIORITY_WEIGHTS.get(job.priority, 1.0)

    delay_penalty = delay * job.delay_weight * priority_factor * inst.weights['delay_penalty']
    compute_cost_weighted = op_compute_cost_raw * inst.weights['compute_cost']

    total_cost = compute_cost_weighted + delay_penalty

    # Add cloud deterrence if using a cloud server, scaled by priority and modified by strain
    if is_cloud:
        # Base deterrence, scaled by duration, priority factor, and dynamic modifier
        total_cost += CLOUD_DETERRENCE_PER_HOUR * op.duration * inst.weights['compute_cost'] * priority_factor * cloud_deterrence_modifier

    # Tie-breaker: prefer earlier starts slightly if costs are otherwise equal
    total_cost += start * 0.0001

    return total_cost


def _is_local_capacity_strained(inst: Instance, capacity_usage: Dict[str, Dict[int, int]], current_time: int, op: Operation) -> bool:
    """
    Checks if there is any compatible local server that can start the operation
    immediately at current_time. Returns True if all compatible local servers
    are busy/down at current_time for this operation.
    """
    for server_id, server in inst.servers.items():
        if not server.is_cloud and server.server_type == op.server_type:
            if has_capacity(inst, capacity_usage, server_id, current_time, op.duration, op.capacity_required):
                return False  # Found at least one local server with immediate capacity, not strained
    return True  # No compatible local server has immediate capacity, it's strained
