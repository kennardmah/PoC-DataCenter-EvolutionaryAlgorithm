<DESCRIPTION>
This edit implements significant improvements to the scheduling heuristic:

1.  **Best-Fit Local Server Search**: Instead of the previous "first-fit" approach for local servers (where the scheduler would pick the first available time slot it found), the algorithm now evaluates *all* compatible local slots within a defined `LOCAL_SEARCH_WINDOW_HOURS`. It then selects the server and start time that yield the *minimal objective cost* for the current operation. This "best-fit" strategy aims for better local resource utilization and cost efficiency by considering more options. The `break` statement that terminated the local server search after the first available slot is removed.

2.  **Job-Level Lookahead for Future Operations**: The `operation_objective` function has been fundamentally enhanced. It no longer just considers the current operation's cost and direct impact on the job's deadline. Instead, it now incorporates a limited lookahead by calling a new helper function, `_simulate_remaining_ops_cost_and_time`. This helper performs a fast, greedy simulation of scheduling all *subsequent operations* of the current job, using a simplified greedy heuristic. The estimated compute cost, cloud usage, and projected completion time from this simulation are then added to the `operation_objective`. This provides a more holistic, job-level understanding of costs and delays, guiding the scheduler to make decisions for the current operation that are globally better for the entire job, rather than just locally optimal.

3.  **Dynamic Local Search Window**: A constant `LOCAL_SEARCH_WINDOW_HOURS` has been introduced to control how far into the future the local server search extends. This parameter can be tuned to balance search complexity and solution quality.

4.  **Hypothetical Capacity Usage for Lookahead**: To ensure the `_simulate_remaining_ops_cost_and_time` function accurately reflects the state *after* the current operation's hypothetical placement, `copy.deepcopy` is used to create a temporary `capacity_usage` state. This prevents actual schedule modifications during lookahead simulation and ensures correct capacity checks.

    "urgent": 5.0,  # Higher weight for urgent jobs
    "high": 2.0,
    "medium": 1.0,
    "low": 0.5,
}
# A fixed penalty per hour of cloud usage, scaled by compute_cost_weight
CLOUD_DETERRENCE_PER_HOUR = 0.5


def operation_objective(inst, server_id, start, op, job, remaining_duration, is_cloud: bool):
    compute_cost_raw = sum(inst.server_cost[server_id][t % inst.time_horizon]
                           for t in range(start, start + op.duration))

    projected_completion = start + op.duration + remaining_duration
    delay = max(0, projected_completion - job.deadline)

    priority_multiplier = PRIORITY_WEIGHTS.get(job.priority, 1.0) # Default to 1.0 for unknown priorities

    # Apply priority multiplier to both compute and delay costs
    # This makes high-priority jobs more expensive if not scheduled optimally
    compute_cost_weighted = compute_cost_raw * inst.weights['compute_cost'] * priority_multiplier
    delay_penalty_weighted = delay * job.delay_weight * inst.weights['delay_penalty'] * priority_multiplier

    total_cost = compute_cost_weighted + delay_penalty_weighted

    # Add cloud deterrence if using a cloud server
    if is_cloud:
        total_cost += CLOUD_DETERRENCE_PER_HOUR * op.duration * inst.weights['compute_cost']

    return total_cost

import copy # Import here to stay within the evolvable block

# Constants for the scheduler (can be tuned)
LOCAL_SEARCH_WINDOW_HOURS = 24 # Look this many hours ahead for the best local slot
PRIORITY_WEIGHTS = {
    "urgent": 5.0,  # Higher weight for urgent jobs
    "high": 2.0,
    "medium": 1.0,
    "low": 0.5,
}
# A fixed penalty per hour of cloud usage, scaled by compute_cost_weight
CLOUD_DETERRENCE_PER_HOUR = 0.5


def _simulate_remaining_ops_cost_and_time(
    inst: Instance,
    job: Job,
    start_time: int,
    current_op_idx: int,
    hypothetical_capacity_usage: Dict[str, Dict[int, int]]
) -> (float, int, float):
    """
    Simulates scheduling for remaining operations of a job to get a more accurate
    projected completion time and future cost.
    Returns (simulated_compute_cost_raw, simulated_completion_time, simulated_cloud_cost_raw).
    """
    # Create a deep copy of the capacity usage to avoid modifying the actual schedule state
    sim_capacity_usage = copy.deepcopy(hypothetical_capacity_usage)
    sim_current_start = start_time
    sim_total_compute_cost_raw = 0
    sim_total_cloud_cost_raw = 0

    for idx in range(current_op_idx + 1, len(job.operations)):
        op = job.operations[idx]
        best_sim_option = (float('inf'), "", False) # (start_time, server_id, is_cloud_choice_bool)
        # We need to ensure a default start time for the min comparison for best_sim_option.
        # Initialize with max_int for start time and a dummy server_id.
        best_sim_option = (float('inf'), -1, None, False) # (score, start_time, server_id, is_cloud)

        # Check cloud first for immediate availability, always a fallback
        for server_id, server in inst.servers.items():
            if server.is_cloud and server.server_type == op.server_type:
                # Cloud: always available immediately
                # For simulation, a simple cost is sufficient
                sim_op_cost_raw = sum(inst.server_cost[server_id][t % inst.time_horizon]
                                  for t in range(sim_current_start, sim_current_start + op.duration))
                sim_score = sim_op_cost_raw + CLOUD_DETERRENCE_PER_HOUR * op.duration

                if sim_score < best_sim_option[0]:
                    best_sim_option = (sim_score, sim_current_start, server_id, True)
                break # Take the first compatible cloud server for simplicity in simulation

        # Check local servers
        for server_id, server in inst.servers.items():
            if not server.is_cloud and server.server_type == op.server_type:
                # Local: search for first available slot within a small window
                # Use a smaller, faster window for lookahead simulation
                for s_start in range(sim_current_start, sim_current_start + LOCAL_SEARCH_WINDOW_HOURS):
                    if has_capacity(inst, sim_capacity_usage, server_id, s_start, op.duration, op.capacity_required):
                        sim_op_cost_raw = sum(inst.server_cost[server_id][t % inst.time_horizon]
                                          for t in range(s_start, s_start + op.duration))
                        sim_score = sim_op_cost_raw

                        if sim_score < best_sim_option[0]:
                            best_sim_option = (sim_score, s_start, server_id, False)
                        break # Take the first available slot to keep simulation fast and greedy

        _, chosen_sim_start, chosen_sim_server, is_cloud_sim_choice = best_sim_option

        if chosen_sim_server is None: # No server found, even cloud (should be rare if cloud is available)
            # This indicates an unfulfillable operation. For simulation, just advance time.
            sim_current_start += op.duration
            continue

        # Reserve capacity for simulation
        for t in range(chosen_sim_start, chosen_sim_start + op.duration):
            sim_capacity_usage[chosen_sim_server][t] = sim_capacity_usage[chosen_sim_server].get(t, 0) + op.capacity_required

        # Accumulate raw compute cost for simulation
        for t in range(chosen_sim_start, chosen_sim_start + op.duration):
            sim_total_compute_cost_raw += inst.server_cost[chosen_sim_server][t % inst.time_horizon]

        if is_cloud_sim_choice:
            sim_total_cloud_cost_raw += CLOUD_DETERRENCE_PER_HOUR * op.duration # Note: not weighted yet

        sim_current_start = chosen_sim_start + op.duration

    simulated_completion_time = sim_current_start
    return sim_total_compute_cost_raw, simulated_completion_time, sim_total_cloud_cost_raw


def operation_objective(inst, server_id, start, op, job, current_op_idx, all_job_operations, hypothetical_capacity_usage, is_cloud: bool):
    current_op_compute_cost_raw = sum(inst.server_cost[server_id][t % inst.time_horizon]
                                      for t in range(start, start + op.duration))

    current_op_cloud_cost_raw = 0
    if is_cloud:
        current_op_cloud_cost_raw = CLOUD_DETERRENCE_PER_HOUR * op.duration

    # Simulate future operations to get a realistic projected completion time and future cost
    simulated_future_compute_cost_raw, simulated_job_completion, simulated_future_cloud_cost_raw = \
        _simulate_remaining_ops_cost_and_time(
            inst, job, start + op.duration, current_op_idx, hypothetical_capacity_usage
        )

    total_compute_cost_raw = current_op_compute_cost_raw + simulated_future_compute_cost_raw
    total_cloud_deterrence_raw = current_op_cloud_cost_raw + simulated_future_cloud_cost_raw

    # Project the overall job completion time (including the current op and simulated future ops)
    projected_completion = simulated_job_completion
    delay = max(0, projected_completion - job.deadline)

    priority_multiplier = PRIORITY_WEIGHTS.get(job.priority, 1.0) # Default to 1.0 for unknown priorities

    # Apply priority multiplier to all cost components
    compute_cost_weighted = total_compute_cost_raw * inst.weights['compute_cost'] * priority_multiplier
    delay_penalty_weighted = delay * job.delay_weight * inst.weights['delay_penalty'] * priority_multiplier
    cloud_deterrence_weighted = total_cloud_deterrence_raw * inst.weights['compute_cost'] * priority_multiplier # Apply to cloud deterrence too

    total_cost = compute_cost_weighted + delay_penalty_weighted + cloud_deterrence_weighted

    # Tie-breaker: prefer earlier starts slightly if costs are otherwise equal.
    total_cost += start * 0.0001 # Small coefficient for tie-breaking

    return total_cost


def schedule_job_online(inst: Instance,
                        job: Job,
                        schedule: Schedule,
                        capacity_usage: Dict[str, Dict[int, int]],
                        current_time: int):

    schedule[job.id] = []
    # op_start_time_for_job for the first operation is the max of job arrival and the current simulation time.
    # For subsequent operations of the same job, it will be updated to the end time of the previous operation.
    op_start_time_for_job = max(job.arrival_time, current_time)

    for idx, op in enumerate(job.operations):
        # Initialize best option for this operation.
        # Tuple format: (total_objective_cost, projected_start_time, server_id, is_cloud_choice)
        # Tie-breaking priority: lower cost, then earlier start, then server_id (alphabetical), then prefer local (False) over cloud (True)
        best_op_candidate = (float('inf'), float('inf'), "", True)

        for server_id, server in inst.servers.items():
            if server.server_type != op.server_type:
                continue

            # Temporary capacity usage for evaluating this specific candidate slot
            # This is important for the lookahead simulation to be accurate.
            # Deep copy to ensure current operation's hypothetical placement doesn't affect other candidates
            # or the lookahead simulation of other candidates.
            hypothetical_cap_usage = defaultdict(dict, {s: d.copy() for s, d in capacity_usage.items()})


            if server.is_cloud:
                # Cloud servers: always available immediately at op_start_time_for_job
                # Hypothethically reserve capacity for current op
                for t in range(op_start_time_for_job, op_start_time_for_job + op.duration):
                    hypothetical_cap_usage[server_id][t] = hypothetical_cap_usage[server_id].get(t, 0) + op.capacity_required

                cost = operation_objective(
                    inst, server_id, op_start_time_for_job, op, job, idx, job.operations, hypothetical_cap_usage, is_cloud=True
                )
                best_op_candidate = min(best_op_candidate, (cost, op_start_time_for_job, server_id, True))
            else:
                # Local servers: search forward for the best available slot within the defined window
                for start in range(op_start_time_for_job, op_start_time_for_job + LOCAL_SEARCH_WINDOW_HOURS):
                    if has_capacity(inst, capacity_usage, server_id, start, op.duration, op.capacity_required):
                        # Hypothethically reserve capacity for current op in this local slot
                        local_hypothetical_cap_usage = defaultdict(dict, {s: d.copy() for s, d in capacity_usage.items()})
                        for t in range(start, start + op.duration):
                            local_hypothetical_cap_usage[server_id][t] = local_hypothetical_cap_usage[server_id].get(t, 0) + op.capacity_required

                        cost = operation_objective(
                            inst, server_id, start, op, job, idx, job.operations, local_hypothetical_cap_usage, is_cloud=False
                        )
                        best_op_candidate = min(best_op_candidate, (cost, start, server_id, False))
                        # DO NOT break here; we want to find the *best* slot within the window, not just the first.

        # Unpack the chosen best option
        _, chosen_start, chosen_server, _ = best_op_candidate

        # Error handling if no slot found (should not happen if cloud is always an option).
        if chosen_server is None:
            # If this happens, it means no compatible server was found or cost remained infinite.
            # This is a critical failure in job scheduling.
            raise RuntimeError(f"No suitable server found for operation {idx} of job {job.id}. This indicates an unfulfillable operation or severe resource contention beyond the search window.")

        # Reserve capacity for the chosen slot in the actual schedule
        for t in range(chosen_start, chosen_start + op.duration):
            capacity_usage[chosen_server][t] = capacity_usage[chosen_server].get(t, 0) + op.capacity_required

        schedule[job.id].append({"server": chosen_server, "start": chosen_start})
        # Update op_start_time_for_job for the next operation of this job
        op_start_time_for_job = chosen_start + op.duration
