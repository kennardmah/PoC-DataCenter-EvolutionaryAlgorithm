This edit modifies the `_calculate_placement_score` helper function to accept an additional parameter `_dynamic_cloud_multiplier`. This factor will be used to dynamically adjust the cloud deterrence penalty based on real-time local capacity availability. This sets the stage for implementing dynamic cloud deterrence in the scheduling logic. The `_dynamic_cloud_multiplier` defaults to 1.0 to maintain current behavior if not explicitly provided.
