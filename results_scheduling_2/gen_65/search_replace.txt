<DESCRIPTION>
This edit refines the scheduling heuristic within `schedule_job_online` by addressing two key areas:
1.  **Best-Fit Local Server Search**: Instead of taking the *first* available slot on a local server, the scheduler will now search within a `LOCAL_SEARCH_WINDOW_HOURS` to find the slot that yields the *minimum objective cost*. This aligns with recommendation 2 ("Replace 'First Available Slot' with Bounded Local Search for Best Fit") and aims to optimize resource utilization and job completion without immediately resorting to more expensive cloud options.
2.  **Dynamic Priority-Sensitive Cloud Deterrence**: The `_calculate_op_score` function (formerly `_calculate_placement_score`) is enhanced. It now incorporates `PRIORITY_JOB_COST_MULTIPLIERS` to make delays and compute costs for higher priority jobs (especially 'emergency') significantly more expensive. Crucially, it introduces a mechanism to *reduce* cloud deterrence for 'emergency' jobs if the best local option would cause a significant delay (defined by `EMERGENCY_CLOUD_TRIGGER_DELAY_THRESHOLD`). This makes the scheduler more flexible and resilient in emergency scenarios, allowing critical jobs to quickly move to the cloud if local resources are bottlenecked, aligning with recommendation 3 ("Integrate Dynamic and Priority-Sensitive Cloud Deterrence").

**Specific Changes:**
*   **Constants**: Tunable constants like `PRIORITY_JOB_COST_MULTIPLIERS`, `CLOUD_BASE_DETERRENCE_PER_UNIT_DURATION`, `CLOUD_EMERGENCY_DISCOUNT_FACTOR`, `LOCAL_SEARCH_WINDOW_HOURS`, `EMERGENCY_CLOUD_TRIGGER_DELAY_THRESHOLD`, and `EMERGENCY_CLOUD_COST_REDUCTION_FACTOR` are defined *within* `schedule_job_online`. This makes them locally scoped and directly adjustable for the online scheduler.
*   **`_calculate_op_score` function**:
    *   Renamed for clarity and encapsulated within `schedule_job_online`.
    *   Now takes `_cloud_deterrence_override_factor` to enable dynamic adjustments to cloud costs.
    *   Applies `priority_factor` to both `op_compute_cost_raw` and `cloud_deterrence_cost` to ensure priority strongly influences all cost components.
    *   The cloud deterrence now applies `CLOUD_EMERGENCY_DISCOUNT_FACTOR` by default for emergency jobs and can be further reduced by `EMERGENCY_CLOUD_COST_REDUCTION_FACTOR` if the `EMERGENCY_CLOUD_TRIGGER_DELAY_THRESHOLD` is met.
*   **Local Search Logic**: The `break` statement in the local server search loop is removed. Instead, it iterates through `LOCAL_SEARCH_WINDOW_HOURS` and uses `min` to find the `best_overall_candidate` among all local and cloud options.
*   **Emergency Cloud Fallback**: After evaluating all initial local and cloud options, if the job is 'emergency' priority and its *best local option* results in a delay exceeding `EMERGENCY_CLOUD_TRIGGER_DELAY_THRESHOLD`, the cloud options are re-evaluated with a *reduced* cloud deterrence (via `EMERGENCY_CLOUD_COST_REDUCTION_FACTOR`). If this re-evaluated cloud option is superior to the current `best_overall_candidate`, it is chosen. This provides a critical escape hatch for urgent jobs in congested or failed local environments.

# Constants for the scheduler
PRIORITY_WEIGHTS = {
    "emergency": 8.0,  # Highest urgency, highest penalty for delay
    "high": 3.0,
    "medium": 1.0,
    "low": 0.5,
}
# A fixed penalty per hour of cloud usage, scaled by compute_cost_weight and priority
CLOUD_DETERRENCE_PER_HOUR = 0.5


def _calculate_placement_score(inst: Instance, server_id: str, start: int, op: Operation, job: Job, remaining_duration: int, is_cloud: bool) -> float:
    """
    Calculates a weighted score for a proposed operation placement,
    considering compute cost, the impact on the job's overall delay penalty,
    and dynamic cloud deterrence based on priority.
    """
    # Compute cost for THIS operation
    op_compute_cost_raw = sum(inst.server_cost[server_id][t % inst.time_horizon]
                              for t in range(start, start + op.duration))

    # Projected completion time for THE ENTIRE JOB
    projected_op_end = start + op.duration
    projected_job_completion = projected_op_end + remaining_duration

    # Calculate the delay penalty for THE ENTIRE JOB.
    delay = max(0, projected_job_completion - job.deadline)

    # Apply priority multiplier to the delay penalty.
    priority_factor = PRIORITY_WEIGHTS.get(job.priority, 1.0)
    delay_penalty = delay * job.delay_weight * priority_factor * inst.weights['delay_penalty']

    # Apply priority multiplier to compute cost as well
    compute_cost_weighted = op_compute_cost_raw * inst.weights['compute_cost'] * priority_factor

    total_cost = compute_cost_weighted + delay_penalty

    # Add cloud deterrence if using a cloud server, scaled by priority
    if is_cloud:
        total_cost += CLOUD_DETERRENCE_PER_HOUR * op.duration * inst.weights['compute_cost'] * priority_factor

    # Tie-breaker: prefer earlier starts slightly if costs are otherwise equal
    total_cost += start * 0.0001

    return total_cost

        # It must start after the current operation finishes.

                        schedule: Schedule,
                        capacity_usage: Dict[str, Dict[int, int]],
                        current_time: int):

    # --- Tunable Parameters ---
    # Priority multipliers for delay penalties and compute costs: higher values make them more costly.
    PRIORITY_JOB_COST_MULTIPLIERS = {
        'emergency': 12.0, # Increased for higher urgency (tuned)
        'high': 5.0,       # Increased (tuned)
        'medium': 1.0,
        'low': 0.5,
    }

    # Base cost per unit of duration to deter cloud usage, making local preferred.
    CLOUD_BASE_DETERRENCE_PER_UNIT_DURATION = 35.0 # Tuned to be slightly higher

    # Discount factor for cloud deterrence specifically for emergency jobs.
    # E.g., 0.8 means cloud deterrence is 20% cheaper (1-0.8 = 0.2 of original cost).
    CLOUD_EMERGENCY_DISCOUNT_FACTOR = 0.8

    # How far into the future local machines search for an optimal slot (in hours).
    LOCAL_SEARCH_WINDOW_HOURS = 24

    # If an emergency job's best local option causes this much delay (or more),
    # consider cloud with significantly reduced deterrence.
    EMERGENCY_CLOUD_TRIGGER_DELAY_THRESHOLD = 5 # hours of delay

    # Additional cost reduction factor for cloud if triggered by emergency threshold.
    # E.g., 0.5 means cloud deterrence is halved (multiplied by 0.5) if triggered.
    EMERGENCY_CLOUD_COST_REDUCTION_FACTOR = 0.5

    def _calculate_op_score(
        _inst: Instance,
        _job: Job,
        _operation: Operation,
        _proposed_start: int,

        _is_cloud_server: bool,
        _remaining_ops_duration: int,
        _cloud_deterrence_override_factor: float = 1.0

        Calculates a weighted score for a proposed operation placement,
        considering compute cost, the impact on the job's overall delay penalty,
        and adding dynamic, priority-weighted cloud deterrence.

        op_compute_cost_raw = sum(_inst.server_cost[_server_id][t % _inst.time_horizon]
                              for t in range(_proposed_start, _proposed_start + _operation.duration))

        # Apply priority multiplier to the delay penalty and compute costs to reflect job urgency.
        priority_factor = PRIORITY_JOB_COST_MULTIPLIERS.get(_job.priority, 1.0)

        cloud_deterrence_cost = 0.0
        if _is_cloud_server:

            cloud_deterrence_cost = CLOUD_BASE_DETERRENCE_PER_UNIT_DURATION * _operation.duration

            if _job.priority == 'emergency':
                # Apply base discount for emergency jobs
                cloud_deterrence_cost *= CLOUD_EMERGENCY_DISCOUNT_FACTOR

            cloud_deterrence_cost *= _cloud_deterrence_override_factor

            # Scale cloud deterrence by overall compute_cost_weight and priority factor
            cloud_deterrence_cost *= _inst.weights['compute_cost'] * priority_factor

        projected_op_end = _proposed_start + _operation.duration
        projected_job_completion = projected_op_end + _remaining_ops_duration

        # Calculate the delay penalty for THE ENTIRE JOB.
        delay = max(0, projected_job_completion - _job.deadline)

        delay_penalty = delay * _job.delay_weight * priority_factor * _inst.weights['delay_penalty']

        # Total score for this specific operation placement.
        total_score = (
            (op_compute_cost_raw * _inst.weights['compute_cost'] * priority_factor)
            + cloud_deterrence_cost
            + delay_penalty
        )

        # Tie-breaker: prefer earlier starts slightly if costs are otherwise equal.
        # This helps break ties consistently and prefers sooner completion.
        total_score += _proposed_start * 0.0001
