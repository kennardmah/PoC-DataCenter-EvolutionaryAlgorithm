<congestion_aware_cloud_deterrence>
This edit implements Recommendation 3: "Introduce Congestion-Responsive Dynamic Cloud Deterrence." It refines the objective function by dynamically adjusting the cloud deterrence factor based on the projected congestion of local machines.

The key changes are:
1.  **New Tunable Parameters**: Introduced `CONGESTION_THRESHOLD_FACTOR`, `CONGESTION_LOOKAHEAD_HOURS`, and `CLOUD_DETERRENCE_CONGESTION_FACTOR` to control the congestion-aware logic.
2.  **Dynamic Cloud Deterrence Calculation**: The `operation_objective` function is enhanced to check the projected capacity usage of a local server (`server_id`) over a `CONGESTION_LOOKAHEAD_HOURS` window. If the average utilization exceeds `CONGESTION_THRESHOLD_FACTOR`, the cloud deterrence for an equivalent cloud server is reduced by `CLOUD_DETERRENCE_CONGESTION_FACTOR`. This makes cloud an appealing option during local congestion, preventing cascading delays and improving resilience.
3.  **Refined Priority Weighting**: `PRIORITY_WEIGHTS` are adjusted and moved into `operation_objective` as a local constant. The `CLOUD_DETERRENCE_PER_HOUR` is also adjusted.
4.  **Objective Function Signature Update**: `operation_objective` now accepts `capacity_usage` and `current_scheduling_time` to enable evaluation of future congestion, necessitating corresponding changes in `schedule_job_online` when calling this function.

This strategy helps balance the desire to use cheaper local resources with the need to offload work to the cloud when local resources are constrained, especially during emergency scenarios.

LOCAL_SEARCH_WINDOW_HOURS = 24 # Look up to 24 hours ahead for the best local slot
PRIORITY_WEIGHTS = {
    "urgent": 5.0,  # Higher weight for urgent jobs
    "high": 2.0,
    "medium": 1.0,
    "low": 0.5,
}
# A fixed penalty per hour of cloud usage, scaled by compute_cost_weight
CLOUD_DETERRENCE_PER_HOUR = 0.5


def operation_objective(inst, server_id, start, op, job, remaining_duration, is_cloud: bool):
    compute_cost_raw = sum(inst.server_cost[server_id][t % inst.time_horizon]
                           for t in range(start, start + op.duration))

    projected_completion = start + op.duration + remaining_duration
    delay = max(0, projected_completion - job.deadline)

    priority_multiplier = PRIORITY_WEIGHTS.get(job.priority, 1.0) # Default to 1.0 for unknown priorities

    # Apply priority multiplier to both compute and delay costs
    # This makes high-priority jobs more expensive if not scheduled optimally
    compute_cost_weighted = compute_cost_raw * inst.weights['compute_cost'] * priority_multiplier
    delay_penalty_weighted = delay * job.delay_weight * inst.weights['delay_penalty'] * priority_multiplier

    total_cost = compute_cost_weighted + delay_penalty_weighted

    # Add cloud deterrence if using a cloud server, scaled by priority
    if is_cloud:
        total_cost += CLOUD_DETERRENCE_PER_HOUR * op.duration * inst.weights['compute_cost'] * priority_multiplier

    return total_cost

# Constants for the scheduler (can be tuned)
LOCAL_SEARCH_WINDOW_HOURS = 24 # Look up to 24 hours ahead for the best local slot

# Congestion parameters for dynamic cloud deterrence (Recommendation 3)
CONGESTION_THRESHOLD_FACTOR = 0.75 # If local capacity usage exceeds 75% on average
CONGESTION_LOOKAHEAD_HOURS = 6     # Look 6 hours into the future for congestion
CLOUD_DETERRENCE_CONGESTION_FACTOR = 0.6 # Reduce cloud deterrence by 40% if congested (i.e., deterrence becomes 60% of base)


def operation_objective(inst: Instance, server_id: str, start: int, op: Operation, job: Job,
                        remaining_duration: int, is_cloud: bool,
                        capacity_usage: Dict[str, Dict[int, int]], current_scheduling_time: int) -> float:

    # Priority multipliers for delay penalties and cost weighting:
    PRIORITY_WEIGHTS = {
        "emergency": 8.0,  # Highest urgency, highest penalty for delay
        "urgent": 5.0,
        "high": 3.0,
        "medium": 1.0,
        "low": 0.5,
    }
    # A base penalty per hour of cloud usage, scaled by compute_cost_weight
    CLOUD_DETERRENCE_PER_HOUR = 0.75 # Slightly increased base deterrence

    compute_cost_raw = sum(inst.server_cost[server_id][t % inst.time_horizon]
                           for t in range(start, start + op.duration))

    projected_completion = start + op.duration + remaining_duration
    delay = max(0, projected_completion - job.deadline)

    priority_multiplier = PRIORITY_WEIGHTS.get(job.priority, 1.0) # Default to 1.0 for unknown priorities

    # Apply priority multiplier to both compute and delay costs
    compute_cost_weighted = compute_cost_raw * inst.weights['compute_cost'] * priority_multiplier
    delay_penalty_weighted = delay * job.delay_weight * inst.weights['delay_penalty'] * priority_multiplier

    total_cost = compute_cost_weighted + delay_penalty_weighted

    # Add cloud deterrence if using a cloud server, scaled by priority
    if is_cloud:
        cloud_deterrence = CLOUD_DETERRENCE_PER_HOUR * op.duration * inst.weights['compute_cost'] * priority_multiplier

        # Check for local congestion to dynamically reduce cloud deterrence (Recommendation 3)
        # Only relevant if considering a local server of the same type
        local_servers_of_type = [s for s in inst.servers.values() if not s.is_cloud and s.server_type == op.server_type]
        is_congested = False
        if local_servers_of_type:
            total_capacity_needed = 0
            total_capacity_available = 0
            for t in range(current_scheduling_time, current_scheduling_time + CONGESTION_LOOKAHEAD_HOURS):
                for local_s in local_servers_of_type:
                    current_usage = capacity_usage[local_s.id].get(t, 0)
                    available_capacity = get_available_capacity(inst, local_s.id, t)

                    total_capacity_needed += current_usage
                    total_capacity_available += available_capacity

            if total_capacity_available > 0: # Avoid division by zero
                avg_utilization = total_capacity_needed / total_capacity_available
                if avg_utilization > CONGESTION_THRESHOLD_FACTOR:
                    is_congested = True

        if is_congested:
            cloud_deterrence *= (1.0 - CLOUD_DETERRENCE_CONGESTION_FACTOR) # Reduce deterrence

        total_cost += cloud_deterrence

    # Tie-breaker: prefer earlier starts slightly if costs are otherwise equal
    total_cost += start * 0.0001

    return total_cost
