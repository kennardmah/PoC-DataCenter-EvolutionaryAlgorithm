<local_n_best_fit>
Evaluate N best initial slots for local machines

Instead of taking the very first available slot on a local machine (greedy first-fit), this modification implements a "N-Best-First-Fit" heuristic. For each local machine, it searches forward to identify the first `N_LOCAL_CANDIDATES_TO_EVALUATE` available slots within its search window. It then evaluates the `operation_objective` for each of these `N` slots and selects the best one for that specific local machine. This "best of N" for the current local machine is then compared against the best cloud option and the best "best of N" options from other local machines.

This approach aims to reduce local sub-optimality by allowing a small lookahead on each individual local machine, without incurring the computational cost of a full exhaustive search over the entire horizon for every machine. By evaluating a few immediate options, it can potentially find a slightly cheaper or less delaying slot for the current operation, leading to better overall job completion times and costs. The `N_LOCAL_CANDIDATES_TO_EVALUATE` constant (set to 3) provides a tunable trade-off between greedy first-fit and more extensive search.

This directly addresses the balance between local vs. cloud cost tradeoffs and capacity contention by making local machine selection smarter.

N_LOCAL_CANDIDATES_TO_EVALUATE = 3 # Evaluate the best of the first N available local slots

def schedule_job_online(inst: Instance,
                        job: Job,
                        schedule: Schedule,
                        capacity_usage: Dict[str, Dict[int, int]],
                        current_time: int):

    schedule[job.id] = []
    current_start = max(job.arrival_time, current_time)

    for idx, op in enumerate(job.operations):
        remaining_duration = sum(o.duration for o in job.operations[idx + 1:])

        best = (float('inf'), None, None) # (cost, server_id, start_time)

        for server_id, server in inst.servers.items():
            if server.server_type != op.server_type:
                continue

            # cloud: immediate start
            if server.is_cloud:
                cost = operation_objective(inst, server_id, current_start, op, job, remaining_duration)
                best = min(best, (cost, server_id, current_start))
                continue

            # local: search forward for the best among N initial available slots
            local_server_candidates = []
            slots_found = 0
            # The search horizon for local machines is up to `job.deadline + inst.time_horizon`
            search_upper_bound = job.deadline + inst.time_horizon

            for start in range(current_start, search_upper_bound + 1): # +1 to include search_upper_bound
                if has_capacity(inst, capacity_usage, server_id, start, op.duration, op.capacity_required):
                    cost = operation_objective(inst, server_id, start, op, job, remaining_duration)
                    local_server_candidates.append((cost, server_id, start))
                    slots_found += 1
                    if slots_found >= N_LOCAL_CANDIDATES_TO_EVALUATE:
                        break # Stop collecting after N candidates for THIS server

            if local_server_candidates:
                # Select the best among the collected N candidates for this specific local server
                best_local_for_this_server = min(local_server_candidates)
                # Compare this with the overall best found so far (could be cloud or another local server)
                best = min(best, best_local_for_this_server)

        _, chosen_server, chosen_start = best

        # Error handling if no slot found. With cloud, this should ideally not happen.
        if chosen_server is None:
            # Fallback for robustness: try to assign to *any* compatible cloud server
            # if somehow all previous logic failed. This should be rare with unlimited capacity cloud.
            for server_id, server in inst.servers.items():
                if server.is_cloud and server.server_type == op.server_type:
                    chosen_server = server_id
                    chosen_start = current_start # Cloud can start immediately
                    break
            if chosen_server is None: # Still no cloud, critical error
                raise RuntimeError(f"Could not schedule operation {idx} for job {job.id}: No compatible server (local or cloud) found after exhaustive search.")

        # reserve capacity
        for t in range(chosen_start, chosen_start + op.duration):
            capacity_usage[chosen_server][t] = capacity_usage[chosen_server].get(t, 0) + op.capacity_required

        schedule[job.id].append({"server": chosen_server, "start": chosen_start})
        current_start = chosen_start + op.duration
