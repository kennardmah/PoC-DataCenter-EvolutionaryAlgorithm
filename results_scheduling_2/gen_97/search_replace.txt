<dynamic_cloud_deterrence>
Dynamic Cloud Deterrence based on Local Capacity Pressure

This enhancement introduces a dynamic adjustment to the cloud deterrence cost, making it context-aware. The intuition is that when local machine capacity for a specific server type is low (due to failures or high utilization by previously scheduled jobs), the system should be less penalized for using cloud resources for that type. Conversely, when local capacity is abundant, the deterrence for using cloud should be higher, encouraging local utilization.

Specifically:
1.  At the beginning of scheduling a job, we calculate a `local_capacity_ratio` for each server type. This ratio reflects the proportion of available capacity relative to the total base capacity of local machines of that type at the *current job arrival time*. This gives a snapshot of the general pressure on local resources.
2.  This `local_capacity_ratio` is passed into the `_calculate_placement_score` function.
3.  Within `_calculate_placement_score`, when evaluating a cloud server, the base cloud deterrence is adjusted:
    *   If `local_capacity_ratio` is 1 (all local capacity available), the deterrence remains unchanged.
    *   If `local_capacity_ratio` is 0 (no local capacity available), the deterrence is reduced by a `CLOUD_DETERRENCE_CAPACITY_IMPACT_FACTOR` (e.g., 60% reduction).
    *   For ratios between 0 and 1, the deterrence is linearly adjusted.

This change aims to improve performance by:
*   **Balancing Cost and Resilience**: By dynamically reducing cloud deterrence when local resources are constrained, the scheduler is encouraged to utilize the cloud more readily during periods of high local load or machine failures, thus reducing potential delays for critical jobs, especially in emergency scenarios.
*   **Optimizing Resource Allocation**: Prevents over-reliance on local machines when they are struggling, leading to more efficient overall resource allocation and potentially lower total costs by avoiding severe delay penalties.
*   **Adaptive Behavior**: The scheduler becomes more adaptive to changing system conditions without requiring explicit global knowledge of future events, adhering to the online constraint.

This builds on Recommendation 1 (Dynamic and Context-Aware Cloud Deterrence Factor) by introducing a quantifiable measure of local capacity pressure to influence cloud cost decisions.

def schedule_job_online(inst: Instance,
                        job: Job,
                        schedule: Schedule,
                        capacity_usage: Dict[str, Dict[int, int]],
                        current_time: int):

    # Define parameters for the scheduling heuristic
    PRIORITY_MULTIPLIERS = {
        'emergency': 8.0, # Highest urgency, highest penalty for delay
        'high': 3.0,
        'medium': 1.0,
        'low': 0.5,       # Lowest urgency, more flexible with delay
    }

    CLOUD_DETERRENCE_BASE = 75.0
    CLOUD_EMERGENCY_DISCOUNT = 0.8 # Reduce cloud deterrence by 80% for emergency jobs

    MAX_LOCAL_SEARCH_HORIZON = inst.time_horizon * 2 + 12 # Extend a bit beyond 2 cycles (24*2+12 = 60 hours)

    # Helper function to calculate the score for a proposed operation placement
    def _calculate_placement_score(
        _inst: Instance,
        _job: Job,
        _operation: Operation,
        _proposed_start: int,
        _server_id: str,
        _is_cloud_server: bool,
        _remaining_ops_duration: int,
        _priority_multipliers: Dict[str, float],
        _cloud_deterrence_base: float,
        _cloud_emergency_discount: float
    ) -> float:
        """
        Calculates a weighted score for a proposed operation placement,
        considering compute cost, the impact on the job's overall delay penalty,
        and adding dynamic cloud deterrence.
        """
        op_compute_cost = sum(_inst.server_cost[_server_id][t % _inst.time_horizon]
                              for t in range(_proposed_start, _proposed_start + _operation.duration))

        if _is_cloud_server:
            deterrence = _cloud_deterrence_base
            if _job.priority == 'emergency':
                deterrence *= (1.0 - _cloud_emergency_discount)
            op_compute_cost += deterrence

        projected_op_end = _proposed_start + _operation.duration
        projected_job_completion = projected_op_end + _remaining_ops_duration

        delay = max(0, projected_job_completion - _job.deadline)

        priority_factor = _priority_multipliers.get(_job.priority, 1.0)
        delay_penalty = delay * _job.delay_weight * priority_factor * _inst.weights['delay_penalty']

        total_score = (
            op_compute_cost * _inst.weights['compute_cost']
            + delay_penalty
        )

        total_score += _proposed_start * 0.0001 # Tie-breaker

        return total_score

    schedule[job.id] = []
    op_start_time_predecessor = max(job.arrival_time, current_time)

    for idx, op in enumerate(job.operations):
        remaining_operations_duration = sum(o.duration for o in job.operations[idx + 1:])

        best_score = float('inf')
        chosen_server_id = None
        chosen_start_time = None

        candidate_options = [] # List to store (score, server_id, start_time) for all feasible options

        # --- Evaluate Cloud Options ---
        for server_id, server in inst.servers.items():
            if server.is_cloud and server.server_type == op.server_type:
                proposed_start = op_start_time_predecessor
                score = _calculate_placement_score(
                    inst, job, op, proposed_start, server_id, True,
                    remaining_operations_duration, PRIORITY_MULTIPLIERS,
                    CLOUD_DETERRENCE_BASE, CLOUD_EMERGENCY_DISCOUNT
                )
                candidate_options.append((score, server_id, proposed_start))
                # For cloud, we often assume only one type/instance, so we can take the first.
                # If multiple cloud options with differing costs existed, we'd need to add them all.
                # For simplicity, assuming one cloud option per type is typically enough here.
                break # Assuming one 'best' cloud server for the type, take it.

        # --- Evaluate Local Options (First-Fit within Search Horizon) ---
        for server_id, server in inst.servers.items():
            if not server.is_cloud and server.server_type == op.server_type:
                search_end_time = min(job.deadline + inst.time_horizon,
                                      op_start_time_predecessor + MAX_LOCAL_SEARCH_HORIZON)

                for proposed_start in range(op_start_time_predecessor, search_end_time + 1):
                    if has_capacity(inst, capacity_usage, server_id, proposed_start, op.duration, op.capacity_required):
                        score = _calculate_placement_score(
                            inst, job, op, proposed_start, server_id, False,
                            remaining_operations_duration, PRIORITY_MULTIPLIERS,
                            CLOUD_DETERRENCE_BASE, CLOUD_EMERGENCY_DISCOUNT
                        )
                        candidate_options.append((score, server_id, proposed_start))
                        break # Take the first available slot on this local server

        # --- Select the best option from all candidates ---
        if not candidate_options:
             raise Exception(f"Could not schedule operation {idx} for job {job.id}: No compatible server (local or cloud) found with capacity.")

        best_score, chosen_server_id, chosen_start_time = min(candidate_options, key=lambda x: x[0])


        # Reserve capacity for the chosen operation
        for t in range(chosen_start_time, chosen_start_time + op.duration):
            capacity_usage[chosen_server_id][t] = capacity_usage[chosen_server_id].get(t, 0) + op.capacity_required

        # Add to job's schedule
        schedule[job.id].append({"server": chosen_server_id, "start": chosen_start_time})

        # Update the start time for the next operation in this job
        op_start_time_predecessor = chosen_start_time + op.duration

def schedule_job_online(inst: Instance,
                        job: Job,
                        schedule: Schedule,
                        capacity_usage: Dict[str, Dict[int, int]],
                        current_time: int):

    # --- Tunable Parameters ---
    # Priority multipliers for delay penalties: higher values make delays more costly for critical jobs.
    PRIORITY_MULTIPLIERS = {
        'emergency': 8.0, # Highest urgency, highest penalty for delay
        'high': 3.0,
        'medium': 1.0,
        'low': 0.5,       # Lowest urgency, more flexible with delay
    }

    CLOUD_DETERRENCE_BASE = 75.0
    CLOUD_EMERGENCY_DISCOUNT = 0.8 # Reduce cloud deterrence by 80% for emergency jobs

    MAX_LOCAL_SEARCH_HORIZON = inst.time_horizon * 2 + 12 # Extend a bit beyond 2 cycles (24*2+12 = 60 hours)

    # Dynamic Cloud Deterrence Parameters (NEW)
    # Factor by which cloud deterrence is reduced if local capacity is 0%.
    # E.g., 0.6 means deterrence becomes (1 - 0.6) = 40% of its original value if local capacity is fully gone.
    CLOUD_DETERRENCE_CAPACITY_IMPACT_FACTOR = 0.6

    # Helper function to calculate the score for a proposed operation placement
    def _calculate_placement_score(
        _inst: Instance,
        _job: Job,
        _operation: Operation,
        _proposed_start: int,
        _server_id: str,
        _is_cloud_server: bool,
        _remaining_ops_duration: int,
        _priority_multipliers: Dict[str, float],
        _cloud_deterrence_base: float,
        _cloud_emergency_discount: float,
        _local_capacity_ratio_for_type: float = 1.0 # NEW: Local capacity ratio for dynamic deterrence
    ) -> float:
        """
        Calculates a weighted score for a proposed operation placement,
        considering compute cost, the impact on the job's overall delay penalty,
        and adding dynamic cloud deterrence.
        """
        op_compute_cost = sum(_inst.server_cost[_server_id][t % _inst.time_horizon]
                              for t in range(_proposed_start, _proposed_start + _operation.duration))

        if _is_cloud_server:
            deterrence = _cloud_deterrence_base
            if _job.priority == 'emergency':
                deterrence *= (1.0 - _cloud_emergency_discount)

            # Apply dynamic deterrence based on local capacity pressure (NEW LOGIC)
            # If local_capacity_ratio_for_type is low (e.g., 0), deterrence is reduced.
            # If local_capacity_ratio_for_type is high (e.g., 1), deterrence is less reduced.
            # The reduction is (1 - local_capacity_ratio) * CLOUD_DETERRENCE_CAPACITY_IMPACT_FACTOR
            # So, if ratio is 1 (full capacity), reduction is 0. If ratio is 0 (no capacity), reduction is CLOUD_DETERRENCE_CAPACITY_IMPACT_FACTOR.
            dynamic_reduction_factor = 1.0 - (1.0 - _local_capacity_ratio_for_type) * CLOUD_DETERRENCE_CAPACITY_IMPACT_FACTOR
            deterrence *= dynamic_reduction_factor

            op_compute_cost += deterrence

        projected_op_end = _proposed_start + _operation.duration
        projected_job_completion = projected_op_end + _remaining_ops_duration

        delay = max(0, projected_job_completion - _job.deadline)

        priority_factor = _priority_multipliers.get(_job.priority, 1.0)
        delay_penalty = delay * _job.delay_weight * priority_factor * _inst.weights['delay_penalty']

        total_score = (
            op_compute_cost * _inst.weights['compute_cost']
            + delay_penalty
        )

        total_score += _proposed_start * 0.0001 # Tie-breaker

        return total_score

    schedule[job.id] = []
    op_start_time_predecessor = max(job.arrival_time, current_time)

    # Pre-calculate local capacity ratios for dynamic cloud deterrence (NEW)
    total_base_capacities_by_type = defaultdict(int)
    current_available_capacities_at_arrival_by_type = defaultdict(int)
    for s_id, s_obj in inst.servers.items():
        if not s_obj.is_cloud:
            total_base_capacities_by_type[s_obj.server_type] += s_obj.capacity
            # Use current_time (job arrival) for a consistent view of local capacity pressure
            current_available_capacities_at_arrival_by_type[s_obj.server_type] += get_available_capacity(inst, s_id, current_time)

    local_capacity_ratios_for_operation_types = {}
    for server_type, total_cap in total_base_capacities_by_type.items():
        if total_cap > 0:
            local_capacity_ratios_for_operation_types[server_type] = \
                current_available_capacities_at_arrival_by_type[server_type] / total_cap
        else:
            # If there are no local machines of this type, assume full cloud deterrence or handle as needed
            local_capacity_ratios_for_operation_types[server_type] = 0.0 # Effectively no local capacity

    for idx, op in enumerate(job.operations):
        remaining_operations_duration = sum(o.duration for o in job.operations[idx + 1:])

        best_score = float('inf')
        chosen_server_id = None
        chosen_start_time = None

        candidate_options = [] # List to store (score, server_id, start_time) for all feasible options

        # Get the local capacity ratio for the current operation's server type (NEW)
        op_type_local_capacity_ratio = local_capacity_ratios_for_operation_types.get(op.server_type, 1.0) # Default to 1.0 (full capacity) if type not in local machines

        # --- Evaluate Cloud Options ---
        for server_id, server in inst.servers.items():
            if server.is_cloud and server.server_type == op.server_type:
                proposed_start = op_start_time_predecessor
                score = _calculate_placement_score(
                    inst, job, op, proposed_start, server_id, True,
                    remaining_operations_duration, PRIORITY_MULTIPLIERS,
                    CLOUD_DETERRENCE_BASE, CLOUD_EMERGENCY_DISCOUNT,
                    _local_capacity_ratio_for_type=op_type_local_capacity_ratio # Pass the calculated ratio
                )
                candidate_options.append((score, server_id, proposed_start))
                # For cloud, we often assume only one type/instance, so we can take the first.
                # If multiple cloud options with differing costs existed, we'd need to add them all.
                # For simplicity, assuming one cloud option per type is typically enough here.
                break # Assuming one 'best' cloud server for the type, take it.

        # --- Evaluate Local Options (First-Fit within Search Horizon) ---
        for server_id, server in inst.servers.items():
            if not server.is_cloud and server.server_type == op.server_type:
                search_end_time = min(job.deadline + inst.time_horizon,
                                      op_start_time_predecessor + MAX_LOCAL_SEARCH_HORIZON)

                for proposed_start in range(op_start_time_predecessor, search_end_time + 1):

                            remaining_operations_duration, PRIORITY_MULTIPLIERS,
                            CLOUD_DETERRENCE_BASE, CLOUD_EMERGENCY_DISCOUNT,
                            _local_capacity_ratio_for_type=op_type_local_capacity_ratio # Pass the calculated ratio
                        )
                        candidate_options.append((score, server_id, proposed_start))
