add_adaptive_search_window_init
</NAME>

<DESCRIPTION>
This edit moves the `MAX_LOCAL_SEARCH_WINDOW_MULTIPLIER` and `MAX_LOCAL_SEARCH_WINDOW_ADD` into `Scheduler.__init__` as instance attributes (renamed to `default_local_search_window_multiplier` and `default_local_search_window_add`).

Crucially, it also introduces several new instance attributes to support an adaptive search window for local machines (as per Recommendation 1):
- `tight_slack_threshold`, `critical_slack_threshold`, `ample_slack_threshold`: define ranges of job urgency based on its remaining slack.
- `tight_window_multiplier`, `tight_window_add`, `critical_window_multiplier`, `critical_window_add`, `ample_window_multiplier`, `ample_window_add`: define specific search window parameters for each urgency level.

These attributes will be used in a subsequent step to dynamically adjust the search window size when looking for local machine slots, allowing the scheduler to prioritize either speed (for urgent jobs) or cost optimization (for less urgent jobs) by looking for slots further in the future.
</DESCRIPTION>
