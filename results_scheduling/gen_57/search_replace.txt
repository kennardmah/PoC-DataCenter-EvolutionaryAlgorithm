Local Server Tie-breaking by Minimal Compute Cost for Same Earliest Start

This enhancement refines the local machine scheduling logic. When multiple local servers can accommodate an operation at the *same earliest start time*, the algorithm will now choose the server that incurs the *lowest compute cost* for that specific operation. This introduces a subtle cost-awareness early in the decision process, which can lead to overall cost reductions without sacrificing the primary goal of minimizing delays.
