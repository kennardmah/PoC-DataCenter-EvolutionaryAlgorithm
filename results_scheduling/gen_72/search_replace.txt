<DESCRIPTION>
This improvement refines the cloud fallback mechanism. Instead of simply picking the *first* available cloud server when local resources are unavailable, the scheduler now iterates through all compatible cloud servers and selects the one with the *lowest compute cost* for the given operation at its earliest possible start time. This is a direct optimization to minimize the `compute_cost` component of the total score when cloud resources are necessary, without incurring additional delay.
</DESCRIPTION>
