local_server_congestion_sort
Sorts local servers by anticipated congestion before attempting to schedule. Instead of an arbitrary order, servers that have more available capacity over the operation's potential execution window (starting from the job's earliest available time) are prioritized. This aims to spread the load more evenly across local machines, reducing the chance of unnecessary cloud spillover or delays due to resource contention.

            # 1. Try to schedule on a local machine (prefer local to minimize cost)
            local_servers = [s.id for s in inst.servers.values() if s.server_type == op.server_type and not s.is_cloud]

            # Sort local servers by anticipated congestion (higher remaining capacity is better)
            # This helps distribute load and potentially find earlier slots more efficiently.
            def calculate_congestion_score(server_id_to_check: str) -> float:
                # Sum of current free capacity over the potential operation duration
                total_remaining_capacity = 0
                for t in range(current_op_start_time, current_op_start_time + op.duration):
                    if t >= inst.time_horizon: # Avoid checking beyond horizon
                        break
                    used = capacity_usage[server_id_to_check].get(t, 0)
                    available = get_available_capacity(server_id_to_check, t)
                    total_remaining_capacity += max(0, available - used)
                return total_remaining_capacity

            # Sort in descending order of remaining capacity (most free first)
            local_servers.sort(key=calculate_congestion_score, reverse=True)
