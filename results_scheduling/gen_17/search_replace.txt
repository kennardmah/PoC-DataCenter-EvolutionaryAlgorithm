<job_dataclass_attributes>
Add `total_duration` and `priority_score` attributes to the `Job` dataclass.

The existing scheduling logic in `construct_schedule` calculates and assigns `job.total_duration` and `job.priority_score` dynamically to `Job` objects. While Python allows this, defining these attributes explicitly in the `Job` dataclass improves type safety, code clarity, and consistency, especially when other parts of the code (like the `_get_op_schedule_cost` function being reintroduced) rely on these attributes being present. This is a best practice for dataclasses.
