<local_server_cost_tiebreak>
Introduces a cost-aware tie-breaking mechanism for local server selection. When multiple local servers can accommodate an operation at the *same earliest start time*, the algorithm now selects the server that minimizes the compute cost for that specific operation. This refines the greedy local search by adding a secondary cost optimization objective, aiming to reduce overall compute cost without sacrificing the primary objective of avoiding delays by finding the earliest possible start time.
