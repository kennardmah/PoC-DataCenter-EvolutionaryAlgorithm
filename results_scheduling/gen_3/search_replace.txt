<DESCRIPTION>
Introduce a small, cost-aware lookahead window for scheduling local (non-cloud) operations. Instead of always taking the earliest feasible start on a local machine, we search a short window (e.g., 4 hours) to pick the start time that minimizes the per-operation cost given the demand-based pricing. This leverages the existing per-hour SERVER_COST structure to shift work to cheaper off-peak slots when it does not violate deadlines, thereby reducing total compute_cost while keeping delay penalties in check. Cloud scheduling remains as a fallback when no cheap local slot is found.
