<DESCRIPTION>
This enhancement refines the operation scheduling logic within `construct_schedule`. Instead of simply picking the earliest available local slot or immediately falling back to cloud if no *immediate* local slot is found, it now performs a more sophisticated cost-benefit analysis.

For each operation:
1.  It iterates through all compatible local machines and all possible start times up to the `time_horizon`.
2.  For each potential local slot, it calculates a `total_objective_cost` which comprises:
    *   The compute cost of the operation on that server at that time.
    *   A projected delay penalty for the *entire job*, considering if this operation's placement would cause the job to miss its deadline. This directly ties the decision to the `delay_penalty` weight.
    *   A proactive `failure_penalty` if the operation is scheduled on a local machine during a predicted failure window. This encourages avoiding machines with known future capacity reductions.
3.  It keeps track of the best local slot (server + start time) that minimizes this `total_objective_cost`.
4.  Concurrently, it calculates the `total_objective_cost` for placing the operation on a cloud server immediately at the `earliest_start` time.
5.  Finally, it compares the best local option's total cost against the cloud option's total cost and selects the one that yields the minimum overall cost.

This strategy balances compute cost, deadline adherence (delay penalty), and resilience against predicted failures, leading to more optimal scheduling decisions compared to a purely earliest-start greedy approach.

    def _calculate_total_objective_cost(server_id: str, start_time: int, op: Operation, job: Job, current_op_index: int) -> float:
        """
        Calculates the estimated cost of scheduling an operation on a given server at a given start time.
        This includes compute cost, an estimate of future delay penalty for the entire job,
        and a proactive penalty for scheduling on failing machines.
        """
        # 1. Compute Cost for this operation
        op_compute_cost = 0.0
        for t in range(start_time, start_time + op.duration):
            if t >= inst.time_horizon:
                # If operation goes beyond time horizon, its cost wraps around per problem description
                op_compute_cost += inst.server_cost[server_id][t % inst.time_horizon]
            else:
                op_compute_cost += inst.server_cost[server_id][t % inst.time_horizon]

        # 2. Projected Delay Penalty for the entire job
        # Duration of operations *after* the current one.
        remaining_op_durations = sum(o.duration for o in job.operations[current_op_index + 1:])

        # Projected completion time of the *entire job*
        projected_job_completion_time = (start_time + op.duration) + remaining_op_durations

        projected_delay = max(0, projected_job_completion_time - job.deadline)
        delay_penalty_contribution = projected_delay * job.delay_weight * inst.weights['delay_penalty']

        # 3. Proactive Failure Avoidance Penalty (only for local machines)
        failure_penalty = 0.0
        if not inst.servers[server_id].is_cloud and inst.machine_failures:
            for f in inst.machine_failures:
                # Check for overlap between operation (start_time, start_time + op.duration)
                # and failure (f.failure_start, f.failure_end)
                if f.machine_id == server_id and f.failure_start < (start_time + op.duration) and f.failure_end > start_time:
                    overlap_start = max(start_time, f.failure_start)
                    overlap_end = min(start_time + op.duration, f.failure_end)
                    failure_overlap_duration = max(0, overlap_end - overlap_start)

                    if failure_overlap_duration > 0:
                        server_capacity = inst.servers[server_id].capacity
                        capacity_impact_ratio = op.capacity_required / server_capacity if server_capacity > 0 else 0

                        # Penalize scheduling on machines that are predicted to fail.
                        # The multiplier (2) makes failure avoidance aggressive, tied to delay cost magnitude.
                        failure_penalty += f.capacity_reduction * capacity_impact_ratio * failure_overlap_duration * inst.weights["delay_penalty"] * 2

        return (op_compute_cost * inst.weights['compute_cost']) + delay_penalty_contribution + failure_penalty
