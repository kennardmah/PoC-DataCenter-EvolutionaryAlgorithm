        def _calculate_min_free_capacity_during_op(self, server_id: str, start: int, duration: int, capacity_req: int) -> int:
            """
            Calculates the minimum remaining free capacity on a server during an operation's execution,
            assuming the operation is placed there. A higher value indicates more resilience.
            """
            min_free_capacity = float('inf')
            for t in range(start, start + duration):
                used_at_t = self._get_current_used_capacity(server_id, t)
                available_at_t = self._get_available_capacity(server_id, t)

For each candidate, it calculates the full objective value (`_calculate_operation_objective_value`) and the minimum free capacity (`_calculate_min_free_capacity_during_op`).
2.  **Objective-Driven Sorting for Local Candidates**: Local candidates are now sorted primarily by their overall objective cost (combining compute and delay penalties). For ties, it prioritizes earlier start times, then higher minimum free capacity (promoting resilience), and finally server ID for deterministic tie-breaking.
3.  **Optimal Cloud Selection**: When considering cloud, it finds the *cheapest* cloud server for the required type (using the `_get_servers_by_type_sorted` logic, which already prioritizes by cost for cloud). It then calculates the objective value for this cloud option.
4.  **Local vs. Cloud Tradeoff**: The best local candidate (if any) is then directly compared against the best cloud candidate using their respective overall objective values. The option with the lower objective value is chosen.
5.  **Tie-Breaking Preference for Local**: Crucially, if both local and cloud options yield the *exact same* objective value and start time, the local server is now explicitly preferred. This ensures maximum utilization of owned resources when performance metrics are equal.
6.  **Adaptive Search Window**: The `search_end_time` logic for local machines remains, allowing for a lookahead to find cheaper slots within a reasonable window, without causing excessive delays.
