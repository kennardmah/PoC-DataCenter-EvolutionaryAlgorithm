    def _calculate_operation_cost(server_id: str, start: int, duration: int) -> float:
        """Calculate the compute cost for an operation on a specific server."""
        cost = 0.0
        for t in range(start, start + duration):
            if t >= inst.time_horizon: # Ensure not to calculate cost beyond time horizon
                break
            cost += inst.server_cost[server_id][t % inst.time_horizon]
        return cost

<NAME>
intelligent_op_scheduling
</NAME>

<DESCRIPTION>
Replaces the basic greedy operation scheduling with a more intelligent multi-objective approach for each operation. It now comprehensively searches for the best available slot considering:
1.  **Compute Cost**: Calculated for the specific operation on a given server and time.
2.  **Delay Penalty**: Considers the impact on the job's deadline if the operation is delayed, incorporating `job.delay_weight`.
3.  **Failure Avoidance**: Introduces a penalty for scheduling on local machines that are experiencing or are about to experience a capacity reduction due to a failure, encouraging proactive migration to other local machines or cloud.
4.  **Local/Cloud Tradeoff**: For high-priority jobs (`CRITICAL` or `HIGH`), it allows for preemptive cloud usage if a local slot would cause significant delay or is not available soon enough, even if slightly more expensive. It still prioritizes finding the best local slot first within a window defined by the job's deadline.
The logic ensures operations are scheduled to meet deadlines while minimizing the weighted total cost (compute + delay + failure penalty).
</DESCRIPTION>
