<refactor_scheduler_logic>
This refactor introduces several key components to the `Scheduler` class for improved scheduling decisions:
1.  **Adaptive Local Search Window**: Class attributes `BASE_LOCAL_SEARCH_WINDOW_MULTIPLIER`, `BASE_LOCAL_SEARCH_WINDOW_ADD`, and `PRIORITY_SEARCH_WINDOW_FACTORS` are added. These allow the search window for available local slots to dynamically adjust based on job priority, prioritizing immediate scheduling for critical jobs and allowing lower-priority jobs to search further for cheaper slots.
2.  **Minimum Free Capacity Calculation**: The `_calculate_min_free_capacity_during_op` method is re-introduced. This function helps assess the resilience of a potential local server slot by calculating the minimum remaining capacity during the operation, which is then used in tie-breaking.
3.  **Comprehensive Objective Function**: The `_calculate_operation_objective_value` method is re-introduced. This function evaluates a potential operation placement by combining both its direct compute cost and the estimated future delay penalty for the entire job, providing a holistic objective for optimization. The previously separate `_calculate_operation_compute_cost` is removed as its logic is now incorporated here.
