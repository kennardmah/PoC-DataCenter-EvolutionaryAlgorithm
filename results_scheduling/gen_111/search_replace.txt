<objective_function_enhancements>
This improvement enhances the objective function (`_calculate_operation_objective_value`) with two strategies:
1.  **Same-Server Continuation Bonus**: A fixed `SAME_SERVER_BONUS` is subtracted from the cost if a critical/high priority job's operation is scheduled on the same local server as its previous operation. This incentivizes keeping related operations together on the same physical machine, which can reduce implicit overheads like data transfer or setup times. This is only applied to local machines to maximize their utility.
2.  **Non-Linear Delay Weight Scaling**: The `projected_delay` is now raised to a power (`NON_LINEAR_DELAY_FACTOR`), making the delay penalty increase non-linearly. This amplifies the penalty for jobs that are projected to be significantly late, pushing the scheduler to prioritize on-time completion for urgent tasks more aggressively.

These changes are designed to improve both cost efficiency (by encouraging local chaining) and deadline adherence (by strongly penalizing long delays), directly addressing key optimization objectives. `last_scheduled_server_per_job` is introduced to track the server used by each job's preceding operation.
