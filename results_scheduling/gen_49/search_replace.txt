<adaptive_local_search_limit>
Adaptive local search limit for urgent jobs.

This modification introduces an adaptive local search horizon for operations. For 'CRITICAL' and 'HIGH' priority jobs, the scheduler will only search for local machine slots that can start within a short window (e.g., 2 hours) from the operation's earliest available start time. If no such local slot is found, it will immediately consider cloud resources. This strategy is designed to proactively prevent delays for urgent jobs, trading off potential local cost savings for improved deadline adherence, especially during periods of high contention or machine failures. Less critical jobs retain the full time horizon for local search to optimize cost.
